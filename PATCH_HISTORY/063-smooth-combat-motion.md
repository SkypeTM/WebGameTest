# 063 · 전투 자세 사이 연속 보간

공격 준비→돌진→타격 반동→복귀, 방어·회복·피격에 연속 transform 보간을 적용한다. 화면 주사율에 맞춰 브라우저가 중간 프레임을 그리며 60fps를 보장하거나 신규 원화 프레임 생성으로 간주하지 않는다. 기존 320ms 타격 및 900ms 종료 유지. reduced-motion 유지. 미리보기와 실제 전투가 같은 렌더러 사용.

프로덕션 빌드·타입 통과. 라이브 버전60c3fed0-660b-4464-b0bf-eda1dd5a85a2. 미리보기 HTTP200 및 연속 보간 CSS 제공 확인. 실제 프레임률 측정 및 중간 원화 생성은 미실시.
