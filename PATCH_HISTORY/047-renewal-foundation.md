# 047 — 게임 리뉴얼 기준과 계정 오디오 설정

## 목표
2026-10-16 사용자 요청 8항을 지속 가능한 작업 계획으로 기록하고 캐릭터별 디자인 기준 및 계정 오디오 저장을 마련한다.

## 범위
- docs/renewal: 전체 기획, 진행 상태, 캐릭터별 고정 디자인 시트.
- 계정 설정 전용 API/DB: 게임 조작권 및 캠페인 버전과 분리.
- 레오나(AR1) 투명 전신 원화 4종(준비/예비동작/타격/회수), 원본 PNG 및 WebP·생성 기록·manifest 추가. 기존 SD 대기를 유지하고 공격 컷인에서 전신 자세를 교체하는 첫 시제품 연결.
- 완성된 기능과 예정된 디자인을 구분한다. 기존 자산을 새 디자인 완료로 표기하지 않는다.

## 검증
- TypeScript 검사 통과.
- 음향 설정 단위 검사 2개 통과(입력 검증, 계정 격리·부분 병합).
- 로컬 API 통합 검사 통과: 인증·출처·잘못된 입력 거부, 두 세션 동기화, 음소거·0 음량 저장, 재로그인 유지. 테스트 계정의 기존 설정 복원.
- 원화 4종 알파 채널 및 1024×1536 자산 변환 확인. 타격 검 끝 잘림을 재생성으로 수정.
- 원격 DB 추가 테이블 생성 완료. 파일 import는 인증 오류였으나 같은 SQL을 D1 query로 실행하여 성공. 기존 게임 데이터 변경 없음.
- 내부 브라우저의 로컬 탭은 연결 실패 화면에 남아 사용자 새로고침 대기. 화면·실제 전투 연속 모션 QA는 아직 통과로 간주하지 않는다.

## 남은 범위
- 전신 4자세는 연속 리깅 애니메이션 완료가 아니다. 발 기준·자세 사이 연결·의상 디테일 일관성을 추가 검증해야 한다.
- AR2~32 전신 제작, AR1 피격/방어/스킬, 전체 HUD 개편, 엔진 비교, 목표 성별/연령의 실제 자산 교체 미완료.
