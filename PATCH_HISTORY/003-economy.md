# 003 경제 시스템

## 작업 목적

실제 계정 간 재료 거래와 팩션 상점·선택형 암시장 거래를 서버 검증으로 연결했다.

## 변경 파일

- `migrations/001-game.sql`
- `lib/store.ts`
- `lib/game.ts`
- `app/api/game/route.ts`
- `app/page.tsx`
- `tests/store.test.ts`

## 패치 내용

```diff
+ market_listing 테이블 추가
+ `marketList`, `marketBuy`, `marketCancel` 트랜잭션 추가
+ 판매자 재료 차감과 구매자 은화 차감을 같은 트랜잭션에서 처리
+ 구매 시 판매자 은화와 구매자 재료를 원자적으로 이전
+ 열린 매물 API 응답 추가
+ 팩션 우호도 상점 추가
+ 희생을 강제하지 않는 암시장 증표 교환 추가
+ 시장·성장 UI 추가
+ 계정 간 거래와 중복 요청 테스트 추가
```

## 주석

NPC 가상 매물이 아니라 실제 계정 보유 재료만 등록된다. 매물 상태와 소유권은 SQLite에서 확인하며 동일 요청 ID는 영수증으로 재생한다.

## 검증 결과

- 자동 테스트 16개 통과
- 타입 검사 통과
- 운영 빌드 통과

## 후속 위험

매물 만료·거래 내역·수수료·완전한 에스크로와 동시 취소 정책은 추가 구현이 필요하다.
