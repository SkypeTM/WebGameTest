# 032 — 모바일 가로 · 태블릿 반응형 레이아웃

## 작업 목적

휴대폰은 가로 플레이를 기준으로 전투·거점·탐사 UI를 재배치하고, 태블릿은 세로와 가로에서 각각 읽기 쉬운 밀도를 유지한다.

## 변경 파일

- `app/style.css`
- `PATCH_HISTORY/README.md`

## 패치 내용

- 휴대폰 가로(최대 760px, 최대 600px 높이): 마을 시설을 3열로 정렬하고, 전투는 탐사대·적을 좌우로 배치했다.
- 휴대폰 가로: 손패는 가로 스크롤 4열로 유지하고, 캐릭터 상세창을 2열로 전환했다.
- 태블릿 세로(761~1199px): 2열 파티, 안정적인 전투 좌우 비율, 3열 손패를 적용했다.
- 태블릿 가로: 3열 파티, 넓은 전장·탐사 2열 구성, 4열 손패를 적용했다.

## 검증 결과

- 740×390 가로 휴대폰 DOM 레이아웃 확인.
- `pnpm typecheck` 통과.
- `pnpm build` 통과.
