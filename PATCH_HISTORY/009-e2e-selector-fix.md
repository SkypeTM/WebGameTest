# 009 E2E 선택자 수정

## 작업 목적

성장·시장 브라우저 시나리오에서 실제 접근 가능한 버튼 이름과 테스트 선택자의 불일치를 수정한다.

## 변경 파일

- `tests/browser/flow.spec.ts`
- `PATCH_HISTORY/009-e2e-selector-fix.md`

## 발견된 실패

`대장간 강화`라는 이름을 기대했지만 실제 버튼 접근 가능한 이름은 `강화 · ◈ 30`이었다. 기능과 서버 상태는 정상이며 테스트 선택자만 실패했다.

## 패치 내용

```diff
- getByRole("button", { name: /대장간.*강화/ })
+ getByRole("button", { name: /강화/ }).first()
```

## 검증 결과

수정 후 전체 브라우저 테스트를 다시 실행한다.
