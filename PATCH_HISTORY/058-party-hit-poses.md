# 058 · 기본 파티 피격 원화 확장

로드맵2 우선. AR2/AR3/AR4 ready 참조로 hit 원화를 각각 생성한다. 기존 공통 motion-hit 타임라인(320ms hit,780ms ready)에 manifest로 연결한다.
캐릭터 정체성·의상·무기손 유지, 투명 배경·무기/발 잘림 검토. 기본 플레이 봇 및 타입 검사 수행. 실제 화면 QA 전 배포 보류.

피격 컷인 대상의 SD 숨김 조건도 확장. 감소된 모션에서는 기존 CSS로 SD 유지. 전투 계산/저장 구조는 변경하지 않음.

검증: 새3종 육안 확인, 총22종 alpha 확인·WebP 변환 성공. 기본 플레이 봇3/3·TypeScript 통과. 실제 피격 화면은 아직 검증하지 않음. 라이브는055 유지.
