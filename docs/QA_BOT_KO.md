# 로컬 기본 플레이 봇

실행: `pnpm qa:bot` (개발 서버 불필요).

결과 요약: `storage/qa-bot/latest.md`. 실패 행동 추적: `storage/qa-bot/latest.json`.
매 실행 결과를 덮어쓰며 3개 고정 시드로 재현한다. 사용자 계정/저장/DB를 읽거나 수정하지 않는다.

범위: 실제 서버가 사용하는 reducer를 통해 프롤로그 7문항→아르켄 기원→입장→전투 카드/턴→보상→이벤트/상인→야영지 귀환. 각 행동 후 저장 직렬화, 버전 증가, 체력/은화 범위를 검사한다. 시나리오당 400행동 제한, 실패 종료코드1. 봇은 최적 전투 AI가 아니므로 패배도 실패로 보고 사람이 원인을 확인한다.

향후 에이전트: 일반 게임 규칙 변경은 봇 결과를 먼저 확인한다. 실패 시 JSON의 마지막 action과 error부터 조사한다. 성공했다고 전체 QA 통과로 표현하지 않는다. UI 배치/애니메이션/이미지/음향은 해당 화면만 Codex 내부 브라우저에서 추가 검증한다. 인증/동시 저장/네트워크는 별도 통합검사한다. 봇은 자동 패치·push·배포를 하지 않는다.

작업 페이지 원본은 `data/roadmap.json`, 공개 주소는 `/roadmap`. 패치마다 상태와 완료 기준을 함께 갱신한다. 비공개 자료·계정·QA 로그는 공개 데이터에 넣지 않는다.

Windows에서는 scripts/run-qa-bot.cmd로도 실행할 수 있습니다. 결과 파일을 열어 PASS/FAIL만 먼저 확인하세요.
