# 037 · 모바일 패널, 유물 만남, 이야기 확장

## 목적
세로/가로 모바일 조작을 패널로 정리하고, 팩션 인물의 유물 제안과 14장 이야기를 보강합니다. 카드 드롭 시 화면 흔들림을 줄입니다.

## 변경 및 검증
아래에 구현 내용과 수행한 검증 범위를 기록합니다.
## 변경 파일과 동작
- `app/page.tsx`, `app/components/PortableMenu.tsx`, `app/portable-ui.css`: 모바일·태블릿 메뉴를 우측 모달 사이드바로 분리. 덱/도감/거점 의뢰 바로가기, 체력·오디오·계정 정보 제공. 세로와 가로 대응, 가로 전장 우선 배치.
- 유물 선택은 기존 조건/효과/저장을 유지하면서 대표 캐릭터 원화와 팩션별 대화로 제시.
- `data/story_chapters.json`: 14장 의뢰 사연·발견·귀환·다음 장 연결. 완료 전 핵심 발견/귀환 기록 숨김.
- `data/relic_encounters.json`: 7개 팩션 대표와 대사.
- `docs/STORY_GUIDE.md`: 세계관, 장별 해금, 인물 감정선, 정본 위치, 구현/기획 경계를 다른 Agent용으로 기록.

## 카드 드롭 수정 원인
- pointerup에서 moved를 즉시 초기화해 합성 click이 사용한 카드를 재선택하던 문제 수정. 키보드 선택은 유지.
- 포인터 선택 시 기본 포커스 스크롤 방지, 전장 스크롤 앵커 제외.
- 효과 nonce마다 모든 캐릭터를 재생성하던 key 제거. 상태 배지/미리보기 추가에 따른 정보창 높이 변화를 고정해 캐릭터 상하 이동 방지.

## 검증
- TypeScript 검사 통과, 기존 카드 키워드 관련 테스트 5개 통과.
- 14장 데이터와 모든 유물 대표 캐릭터 ID 연결 검사 통과.
- Codex 내부 브라우저 localhost: 가로 844×390 메뉴 열기/닫기, 카드 실제 드래그 사용 후 손패 감소와 선택 해제, 스크롤 Y=0 유지 확인.
- 세로 390×844 사이드바 및 덱 팝업 연결, 태블릿 1024×768 가로 넘침 없음 확인. 브라우저 오류 없음.
- 광범위 전투 회귀 테스트는 요청에 따라 생략. 유물 실제 입장 흐름 및 14장 전체 플레이는 이번 검증 범위 밖.

## 후속
- 별도 스토리 수집/호위 목표·분기 결말·음성·컷신은 미구현. 기존 보스 격파+안전 귀환 판정 유지.
