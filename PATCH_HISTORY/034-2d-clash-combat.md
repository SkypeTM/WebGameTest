# 034 · 2D 합 전투 연출

## 작업 목적
기존 전투의 3D 표현 의존을 제거하고, 카드 선택 단계의 합선·위력 표기와 2D 컷인·타격 이펙트를 추가한다.

## 변경 파일
- `app/page.tsx`
- `app/style.css`
- `public/assets/effects/combat-slash-crimson-v1.png`

## 패치 내용
- 선택 카드와 유효 대상 사이에 애니메이션 합선을 표시한다.
- 대상별 합 위력 배지와 선택 카드의 실시간 계산값을 표시한다.
- 공격 해결에 2D 컷인, 결과 레이블, 생성한 검격 이미지 이펙트를 적용한다.

## 검증
- 타입 검사, 프로덕션 빌드, 로컬·라이브 URL 점검을 완료한다.

## 후속 작업
- 합 판정의 다단계 코인 규칙과 음성 연동은 별도 전투 규칙 패치에서 확장한다.
