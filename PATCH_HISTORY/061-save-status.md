# 061 · 정상 저장 중 재연결 경고 수정

2026-10-19 라이브 QA 계정에서 탐사 시작·유물 선택·첫 전투·에델 기본 타격 실행. 적 HP30→19, 손패6→5, 행동력5→4 확인. SD 배치와 투명 몬스터 표시 확인. 짧은 전신 애니메이션 전체 프레임은 아직 검증하지 못함.

정상 요청 처리 중에도 pending.current가 존재해 오류 배너가 표시됨. busy인 정상 저장은 저장 안내로 분리하고 실제 오류/미확인 요청의 재시도 기능은 유지한다. 모바일 정상 저장은 기존 healthy 상태와 동일하게 처리해 배너로 인한 배치 변화를 줄인다.
