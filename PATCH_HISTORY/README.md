# 패치 히스토리

이 폴더는 프로젝트 변경을 작업 단위로 기록합니다.

각 패치 파일은 다음 순서를 따릅니다.

1. 작업 목적
2. 변경 파일
3. 패치 내용
4. 코드 주석 및 설계 이유
5. 검증 결과
6. 남은 위험 또는 후속 작업

앞으로의 모든 코드 변경은 편집 전에 다음 번호의 `NNN-*.md` 파일을 만들거나, 작업이 작으면 해당 파일을 먼저 갱신한 뒤 편집합니다. 패치 내용은 전체 원문 diff를 기준으로 작성하고, 불필요한 생성물·빌드 산출물은 기록하지 않습니다.
