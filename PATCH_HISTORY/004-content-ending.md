# 004 콘텐츠 경로·엔딩·환생

## 작업 목적

원본 56종 몬스터를 7개 맵 경로에 연결하고, 최종 귀환 뒤 엔딩 선택과 선택형 환생을 제공했다.

## 변경 파일

- `lib/game.ts`
- `app/page.tsx`
- `tests/game.test.ts`

## 패치 내용

```diff
+ M09~M56을 6개 추가 맵의 전투 경로에 연결
+ 각 맵에 일반·정예·보스·휴식 분기 추가
+ 모든 `*-boss` 방에 보상·돌파 판정 적용
+ Game.ending, endingUnlocked, endingHistory, rebirths, legacy 추가
+ `chooseEnding` 행동 추가
+ `rebirth` 행동과 최대 3개 계승 재료 검증 추가
+ 엔딩·환생 거점 UI 추가
+ 7개 맵과 환생 상태 전용 테스트 추가
```

## 주석

원본 몬스터의 ID와 보상은 보존했지만 M09~M56의 고유 행동은 아직 공통 전투 규칙을 사용한다. 엔딩과 환생은 서버 상태 전이로만 확정된다.

## 검증 결과

- 자동 테스트 17개 통과
- 타입 검사 통과
- 운영 빌드 통과

## 후속 위험

48종 고유 행동, 32명 고유 카드, 16개 후일담 조합은 아직 완성되지 않았다.
