# 078 — 모바일 지도 노드 겹침 수정

## 목적
- 390×844 화면에서 지도 노드가 서로 겹치고 오른쪽이 잘리는 실제 결함 수정.

## 변경
- 기존 모바일 `.room` 고정 너비가 절차적 지도의 비율 기반 칸 너비를 초과함. 지도 범위에만 너비 제한 적용 예정.

## 검증
- 수정 전 화면 및 DOM 측정: 칸 60.59px, 버튼 150px.
- 후속: 모바일·태블릿 선택/취소/이동, 로드맵 및 검증 기록 갱신.

## 완료된 변경 파일
- app/art-direction.css: 지도 버튼을 부모 칸 너비에 제한하고 모바일 공통 최소 너비 제거.
- app/route-briefing.css: 모바일 가로 경로 선택 시 지도 패널이 전체 열을 사용하여 사이드바 공간 확보.
- data/roadmap.json: 실제 검증 범위와 남은 실기기 검증을 분리 기록.

## 실제 브라우저 검증 결과
- Codex 내부 localhost 로그인 세션에서 이어하기 조작권 복원.
- 첫 전투: 공격·카드 선택 해제·턴 전환·적 보호막·처치·보상·저장 v17 정상.
- 390×844: 노드 겹침 수정 확인, Escape 취소 및 원래 노드 포커스 복귀.
- 844×390: 지도 폭 축소 수정 확인, 선택 패널과 취소/이동 버튼 표시 정상.
- 768×1024 및 1024×768: 경로 선택 패널 표시 정상.
- 태블릿 가로에서 암상인 이동, 투명 전신 이미지, 거래 종료 후 지도 복귀 확인.
- 실제 모바일 기기 터치·청취·성능은 미검증. 반응형 브라우저 검증을 실기기 통과로 취급하지 않음.
