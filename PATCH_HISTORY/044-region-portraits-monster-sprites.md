# 044 — 지역 미리보기·탐사 대형·몬스터 원본 수정

## 목표와 변경
- 출발 지역 선택에 맞춰 작전실 상단 삽화를 `sceneAsset`의 지역 배경으로 표시. 고정 성곽 도형과 FRONTIER 문구를 제거하고 지역 코드 및 보스 이름도 선택 지역과 일치시킴.
- 작전실 파티 초상화를 얼굴 중심으로 확대. 전투/도감의 전신 이미지는 유지.
- 탐사 경로의 대원 표시를 좌→우 4·3·2·1 순서로 변경. 서버의 실제 파티 배열과 전열 판정은 변경하지 않음.
- 후속 지역 몬스터의 공격/피격 표시가 오래된 잘린 상태 이미지로 돌아가지 않도록 단일 전신 스프라이트를 사용. 기존 이동·타격 애니메이션은 유지.
- 후속 지역 전신 스프라이트를 투명 PNG 원본과 WebP 배포본으로 관리. `build-sd-assets.mjs`가 SD/몬스터/Live2D 매핑을 함께 갱신하고 완전히 불투명한 알파 채널은 거부.

## QA (2026-10-15)
- 자동 테스트 41/41 통과, TypeScript 검사 통과.
- 새 프롤로그 8개 팩션의 질문 순서, 출발 파티, 시작 지역, 저장 복구 검사 추가.
- 기존 테스트는 프롤로그 이전 저장 형식임을 명시. normalizeGame의 불필요한 undefined prologue 키를 제거하여 재요청 영수증 상태 비교 일치.
- 로컬 HTTP 실제 계정: 전투·유물·보스·보상·야영지 귀환·로그아웃/재로그인 저장 흐름 통과(최종 v105).
- Codex 내부 브라우저: 얼굴 초상화, 편성 버튼, 전투 렌더링, 카드 선택/다른 영역 클릭 해제, 모바일 메뉴/덱 팝업 확인.
- 390×844 / 844×390 / 768×1024 / 1024×768 전투 DOM 폭 검사: 수정 후 가로 넘침 없음.
- 확인한 전투 화면의 이미지 로드 실패 없음.

## 범위와 남은 확인
- 모든 분기 대사와 모든 장비 조합을 사람처럼 끝까지 플레이한 검증은 아님.
- 실제 모바일 기기 성능 및 오디오 청음 품질은 미검증.
- 기존에 남아 있던 3D 작업 및 오디오 변경 파일은 본 패치에 포함하지 않음.
- 라이브 배포/검증 결과는 후속 기록으로 보완.
