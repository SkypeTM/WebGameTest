# 056 · 모바일 경로 선택 시트

목적: 모바일에서 경로 선택 후 지도 아래로 스크롤하지 않고 안내·취소·이동 버튼을 사용한다.
작은 화면에서는 하단 고정, 낮은 가로 화면에서는 우측 패널로 표시한다. 기존 이동 확인과 저장 규칙을 유지한다.
검증 및 배포: 진행 중.

구현: 1024px 이하 하단 패널, 600px 이하 낮은 가로 화면 우측 패널. 안내만 내부 스크롤하고 취소/이동 버튼은 항상 유지. 44px 터치 높이와 안전 영역 적용.
검증: qa:bot 3/3, TypeScript 통과. 기존 localhost 탭이 연결 실패 페이지여서 사용자 새로고침 요청. 시각 검증 전 배포 보류.
