# 013 선택 대상 피해 적용 수정

## 작업 목적

M01 방어벽이 다른 몬스터를 선택한 공격까지 전부 가로채 선택 대상의 HP가 그대로 보이는 문제를 수정한다.

## 변경 파일

- `lib/game.ts`
- `tests/game.test.ts`
- `PATCH_HISTORY/013-selected-target-damage-fix.md`

## 원인

공격 처리에서 M01에 방어막이 있으면 선택 대상과 무관하게 `target`을 M01로 교체했다. 따라서 M02를 눌러도 M02 HP가 감소하지 않았다.

## 패치 내용

```diff
- 방어막이 있는 M01을 선택 대상 대신 강제로 피해 대상으로 지정
+ 플레이어가 선택한 적을 항상 피해 대상으로 유지
+ M01 방어막은 M01을 직접 공격할 때만 피해를 흡수
```

## 검증 결과

- 선택 대상 피해 회귀 테스트 추가
- IDE 진단에서 `lib/game.ts`, `tests/game.test.ts` 오류 없음
- 타입 검사와 게임 테스트 실행 완료
- 개발 서버 재시작 후 브라우저에서 기존 전투를 새로고침해야 새 번들이 적용됨
