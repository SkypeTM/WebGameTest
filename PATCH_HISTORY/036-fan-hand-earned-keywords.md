# 036 · 전투 손패와 획득형 카드 키워드

## 변경
- 전투 화면 하단에 겹쳐지는 부채꼴 손패, 선택 카드 확대, 행동력 ◆ / 마나 💧 코스트 아이콘 적용.
- 전투 HUD 축약, 모바일 가로 및 태블릿/데스크탑 카드 크기 조정. 카드에는 이름·핵심 수치 중심으로 표시하고 선택 안내에 상세 효과 제공.
- 기본 파티 AR1–AR4 전용 스킬 일러스트 4장 신규 생성. 그 외 카드는 소유 캐릭터의 기존 SD 이미지 사용.
- 기본 카드 고정 키워드 제거. 암상인: 집중 일격 보존 각인(30 은화, 탐사 한정). 긍정 사건: 선두 기본 타격 보존. 유물: 집중 일격 복사/소멸, 방어 보존, 전용 스킬 발견.
- 레벨 3 방어 보존, 레벨 5 전용 스킬 발견. 거점 훈련장 상위 전직(레벨 5, 80 은화) 시 전용 스킬 생성 해금.
- 저장 정규화·덱 미리보기·실제 전투에서 동일한 획득 키워드 계산. 중복 각인/전직 거절 및 탐사 한정 효과 분리.

원본: `art-source/cards-v2`; 배포 이미지: `public/assets/cards-v2`.

## 검증 및 범위
- 기존 작업 중 타입 검사 및 게임/저장/키워드 테스트 32개 통과.
- Codex 내부 로컬 화면에서 부채꼴 손패·코스트 표시·대상 선택 확인. 방어 카드 제출 후 저장 응답의 최종 확인은 사용자 요청으로 추가 QA를 중단하여 미완료.
- 사용자 지시에 따라 이번 마무리는 빌드 및 배포 성공 여부만 확인하며 광범위한 재검증을 반복하지 않는다.
- 모든 캐릭터/카드 조합의 신규 개별 일러스트 제작은 미완료. 기본 파티 전용 스킬 4장 외에는 기존 캐릭터 SD 자산을 재사용한다.
- 모바일에서 선택 카드 확대가 전투 일부를 가릴 수 있어 추후 필요 시 간격을 조정한다.
