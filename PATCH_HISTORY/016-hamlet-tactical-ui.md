# 016 — 마을 허브와 전술 전투 UI

## 작업 목적

- 탭 중심 화면을 클릭 가능한 중세 마을 허브와 장소 오버레이로 교체한다.
- 탐험 파티의 1열~4열 순서를 명확히 하고 편성 화면에서 재배치할 수 있게 한다.
- 캐릭터 장비, 스트레스, 부상, 보호막과 적 디버프를 전투 중 설명 가능한 형태로 표시한다.
- 마우스와 터치 카드 드래그 중 실제 서버 규칙 기반 결과를 미리 보여준다.
- 다음 지역 선택 뒤 확인 버튼을 눌러야 이동하도록 변경한다.

## 패치 내용

- 실재 중세 성곽 마을의 중앙 광장·성문·방사형 길 구조를 참고한 마을 배경과 건물 핫스폿을 적용했다.
- 작전실에서 1 전열~4 후열을 직접 재배치하고 서버에 즉시 저장할 수 있게 했다.
- 장비, 보호막, 반격, 스트레스, 부상, 표식, 기절의 효과 설명을 전투 UI에 추가했다.
- 카드 포인터 드래그를 마우스와 터치에서 지원하며 실제 리듀서 결과로 피해·보호막·반격을 예측한다.
- 지역을 먼저 선택한 뒤 `탐사 진행`을 눌러 이동하도록 변경했다.
- 56개 전리품, 8개 팩션, 2개 장비, 6개 상태/역할 스프라이트를 생성하고 개별 파일과 매니페스트로 분리했다.
- 32명 전원의 기본·공격·피격·스킬·대화·진급 이미지 192개를 생성하고 전투 모션, 모집, 진급 표시와 연결했다.
- 첨부 예시의 선택형 인벤토리 구조를 적용해 소지품 격자, 큰 상세 이미지, 수량, 분류, 간단한 설명을 표시한다.
- Windows에서 `tsx`의 사용자 정보 조회가 실패하는 환경을 위한 테스트 등록기와 독립 E2E 서버 실행기를 추가했다.
- 상태 정규화가 기존 `run` 객체를 얕게 재사용하던 문제를 고쳐 카드 미리보기가 저장 상태를 변경하지 않게 했다.

## 코드 주석 및 설계 이유

- 파티 배열 순서를 서버 저장되는 전투 배치 순서로 사용해 별도 상태의 불일치를 피한다.
- 카드 예상 결과는 전투 리듀서를 복제 상태에 적용해 실제 판정과 같은 규칙을 사용한다.
- 포인터 이벤트를 사용해 마우스와 터치를 하나의 드래그 흐름으로 처리한다.
