# Silent Bell Story Design Pack v1

이 폴더는 `침묵의 종 아래`의 공통 프롤로그 + 시작 팩션 + 초기 파티 + 주점 모집 + 환생 연계 설계팩입니다.

## 파일
- `PROLOGUE_FACTION_AFFINITY_KO.md`
- `PROLOGUE_SCORING_MATRIX.md`
- `prologue_scoring_v1.json`
- `FACTION_START_PARTY_DESIGN_KO.md`
- `faction_start_design_v1.json`
- `AGENT_HANDOFF_FACTION_PROLOGUE.md`

## 사용 순서
다른 Agent는 먼저 기존 `STORY_GUIDE.md`, `STORY_SCRIPT_KO.md`를 읽고,
그 다음 `AGENT_HANDOFF_FACTION_PROLOGUE.md`를 읽은 뒤 나머지 설계 파일을 참고하세요.

## 상태
이 설계팩은 기존 정본을 보존한 상태의 **확장 제안 v1**입니다.
특히 신규 Q00, 시작 파티 실제 캐릭터 명단, 환생 저장 스키마, 엔딩 분기는 아직 구현 정본이 아닙니다.
