# 8개 팩션 시작 구조 및 기본 파티 설계 v1

- 상태: **신규 설계안**
- 기존 정본 유지 대상: 팩션 코드/이름, Q01~Q14의 핵심 사건, 기존 NPC/대사/보상 ID
- 신규 제안 대상: 팩션별 Q00, 시작 파티 역할, 전투 정체성, 일부 시작 소지역, 비선형 진입 구조

## 공통 시스템 원칙

```text
Origin Faction      = 이번 회차의 출신/시작 세력
Faction Reputation = 현재 각 팩션과의 관계
Party Composition  = 현재 편성된 캐릭터
Story Lead         = 탐사 시작 시 고정되는 파티 1번 캐릭터
```

- 네 값은 서로 독립적이다.
- 타 팩션 캐릭터를 주점에서 모집해도 Origin은 바뀌지 않는다.
- Story Lead는 탐사/챕터 진입 시 고정하고, 대화 직전 슬롯 변경으로 선택지를 악용하지 못하게 한다.
- 캐릭터 개인 충성도/신뢰와 팩션 전체 우호도는 분리한다.
- 환생하면 Origin을 다시 선택할 수 있다.

# 주점 모집 시스템

## 1. 동일 팩션
- 기본적으로 모집 조건이 가장 낮다.
- 비용/신뢰 요구치가 낮고 초기부터 등장 가능.

## 2. 우호 팩션
- 일정 Reputation 이상이면 정식 모집 또는 짧은 소개 이벤트 후 모집.
- 추천 기준값(튜닝 대상): `Reputation >= +20`.

## 3. 중립 팩션
- 처음에는 `Guest` 상태로 합류 가능.
- 일정 탐사 횟수/개인 이벤트 후 `Companion`으로 전환.

## 4. 적대 팩션
- 일반 모집 차단.
- 단, `Character Trust`가 높거나 잔향 기억/개인 퀘스트 조건을 충족하면 팩션과 별개로 합류 가능.

### 핵심 상태 분리

```text
Faction Reputation != Character Trust
Origin Faction      != Party Membership
Party Slot 1        == Story Lead (탐사 진입 시 lock)
```

# 혼합 팩션 파티

- 타 팩션 조합은 단순 페널티가 아니라 `갈등 → 관계 이벤트 → 고유 시너지` 구조로 설계한다.
- 예: AR+EF는 초기에는 명령/자율성 충돌 디버프, 관계 해결 후 구조 상황 특수 시너지.
- 특정 팩션 캐릭터가 있으면 던전의 문, 증언, 우회로, 협상 옵션이 바뀔 수 있다.

# 메인 스토리 비선형화 권장

기존 Q01→Q14를 완전한 무작위 순서로 풀지는 않는다.
대신 7개 지역의 '2개 퀘스트 묶음'을 조사 노드로 보고, 시작 팩션이 첫 노드를 바꾸는 방식이 안전하다.

궁전 진입에 필요한 핵심 증언은 기존 Q13 설정을 유지해 다음 네 계열로 잡는다.

1. 요새의 명령
2. 서고의 기록
3. 예배당의 공명
4. 관측소의 예언

항구와 연구동은 이 네 증언을 연결하고 의미를 뒤집는 중간 핵심 노드로 사용한다.

따라서 시작 지역이 달라도 최종적으로 플레이어는 여러 지역의 증언을 모아야 하며, 어느 순서로 진실을 알았는지가 대사/우호도/엔딩 조건에 영향을 주게 한다.

# 환생과 시작 팩션

- 환생 후 모든 8개 팩션을 다시 선택 가능.
- 이전 회차에서 모집한 캐릭터 자체는 기본적으로 초기화.
- 일부 `인연의 잔향`, 기억, 유물만 계승 가능.
- 이전 회차 동료를 다시 만났을 때 잔향 전용 대사/조기 신뢰 옵션을 열 수 있음.
- 프롤로그 성향도 재검사 가능하지만 팩션 선택은 끝까지 자유.

# 아직 확정하면 안 되는 항목

- 레오나=AR, 마리엔=WS, 에델=DS, 세린=EF는 **설계 후보**일 뿐 이 두 소스 문서만으로는 팩션 소속 정본을 확정할 수 없다.
- 실제 캐릭터 이름/클래스/스킬은 프로젝트의 캐릭터 데이터 확인 후 연결해야 한다.
- 신규 Q00은 아직 실제 퀘스트 ID/보상/저장 필드에 추가된 것이 아니다.
