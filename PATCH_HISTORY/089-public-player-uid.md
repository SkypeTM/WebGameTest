# 089 — 계정별 공개 탐사자 UID

- 인증 계정 ID와 별개인 무작위 공개 UID를 별도 테이블에 저장.
- 본인 세션으로만 조회. 계정/UID 고유 제약으로 중복 발급과 동시 요청 처리.
- 마이페이지에서 UID 표시, 실패 시 재시도. 게임 저장 API와 분리하여 프로필 오류가 게임 진행을 막지 않음.
- 친구 검색·초대·승인 관계는 후속 구현. UID만으로 다른 계정 정보를 조회하는 API는 제공하지 않음.
- 배포 전에 0003_public_profiles.sql 마이그레이션 필요.

- 타입 검사 및 SQLite UID 유지/충돌/동시 발급 검사 통과. 로컬 테이블 적용 완료.
- 로컬 서버 수신 확인. 브라우저 연결 실패 페이지 정책 차단으로 화면 검증 대기. 라이브 DB/배포 미반영.
