# 031 — 2D 전투 액터 복귀

## 작업 목적

Blender/WebGL 3D 전투 액터 사용을 전면 중지하고, 전투의 캐릭터와 몬스터를 기존 2D 스프라이트 경로로 통일한다.

## 변경 파일

- `app/page.tsx`

## 패치 내용

- `BattleActor`가 `Actor3D`를 선택하지 않고 항상 `Crest` 2D 스프라이트를 렌더링하도록 변경했다.
- 기존 2D 상태별 자산 선택과 이미지 실패 시 SVG 폴백을 유지했다.
- 3D 코드와 GLB 자산은 삭제하지 않아, 향후 별도 작업에서 다시 검토할 수 있다.

## 검증 결과

- `pnpm typecheck` 통과.

## 후속 작업

- 2D 캐릭터·몬스터 아트의 원화 품질과 상태별 스프라이트를 별도 개선한다.
