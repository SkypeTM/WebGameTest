# 027 — WebGL 3D 전투 캐릭터

## 작업 목적

- 기본 파티 4명과 변경 요새 몬스터 8종을 평면 스프라이트 대신 실제 WebGL 3D 객체로 표시한다.
- 평상시 SD 비율과 카드 공격 시 풀사이즈 비율을 구분하고 동작이 이어지게 한다.

## 변경 파일

- `app/components/Actor3D.tsx`: 12종 절차적 3D 모델, 조명, 카메라, 애니메이션
- `app/page.tsx`: 전투 SD 모델 및 풀사이즈 공격·피격 컷 전환
- `app/style.css`: 3D 캔버스 크기, 호버 하이라이트, PC·모바일 연출
- `package.json`, `pnpm-lock.yaml`: Three.js WebGL 런타임
- `tests/browser/flow.spec.ts`: 3D 컷 전환 브라우저 검증

## 패치 내용

- 레오나·세린·마리엔·에델의 체형, 팩션 색, 무기 실루엣을 구분한 SD/풀사이즈 3D 모델을 추가했다.
- M01~M08을 방패병, 비행체, 폭탄 딱정벌레, 깃발 구름, 기계견, 다중 방패병, 쌍검 기사, 성탑 짐승 형태로 모델링했다.
- 호흡, 부유, 공격 전진, 피격 흔들림, 사망 쓰러짐을 실시간 애니메이션으로 처리한다.
- 카드 사용 시 SD 객체에서 풀사이즈 3D 컷으로 전환하고, 대상도 풀사이즈 피격 동작을 실행한다.
- 마우스 호버·키보드 포커스·카드 대상 지정 시 모델 외곽 광원을 강화한다.
- WebGL 미적용 캐릭터와 지역은 기존 고해상도 이미지로 자동 대체한다.

## 검증

- 타입 검사, 게임 규칙 테스트, 프로덕션 빌드
- Playwright로 HD 초상화, 절차적 지도, 3D SD 모델과 풀사이즈 전투 컷 확인

## 후속 작업

- 나머지 팩션 캐릭터와 후속 지역 몬스터 3D 모델 확장
- 향후 전용 GLB 리깅 자산이 준비되면 현재 절차적 메시를 같은 컴포넌트에서 교체
