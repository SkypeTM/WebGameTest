# 작업 단위별 배포 지침

사용자 지시: 2026-10-29, 작업할 때마다 라이브 배포.

- 완성한 작업 단위의 소스·자산·로드맵·패치 기록을 함께 커밋하고 GitHub에 푸시한다.
- 해당 커밋을 배포 전용 체크아웃에서 빌드하고 Cloudflare에 배포한다. 다른 미완료 변경을 섞지 않는다.
- 현재 QA 생략 요청 유지. 빌드는 배포 필수 단계이며 화면·플레이 QA 통과로 표현하지 않는다.
- 배포 명령 성공과 버전 ID를 기록한다. 실패하면 미배포 상태를 명시한다.
- 아직 제작하지 않은 SD·전투 모션·NPC를 완료로 표시하지 않는다.
