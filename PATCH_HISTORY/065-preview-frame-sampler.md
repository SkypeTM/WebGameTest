# 065 · 미리보기 프레임 간격 측정

연출 미리보기에서 3초 requestAnimationFrame 간격을 수집한다. 평균 콜백 빈도,95백분위 간격,50ms 초과 간격을 표시한다. 실제 GPU 렌더 완료 FPS나 전투 전체 성능 보장으로 표현하지 않는다. 백그라운드 이동 시 측정 중단, 재측정·언마운트 시 RAF 정리. 계정/서버로 측정값 전송 없음. 반복 체크박스의 공통 input 스타일 침범 수정.

검증: 빌드·타입 통과. 라이브f88fe2fe-e0c7-4f92-b298-3d1f9ee6e539에서 반복 재생 중3초 샘플 평균68.7Hz,95%간격15.1ms,50ms초과0/207 확인. 실제 렌더FPS 보장 아님. 반복 체크박스 크기 및 on/off 확인. docs/renewal/065-frame-sample.png.
