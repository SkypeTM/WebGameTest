# 094 — 탐사 구역 표시와 3단계 승급 제작 계획

- 요청: 미개방 구역 회색 가림, 호버/키보드 해금 조건, 선택 구역 외곽 강조.
- 일곱 구역별 서로 다른 건축·지형 원화와 출정 준비 배경을 별도 제작한다.
- 캐릭터별 1/2/3단계 의상·무구 원화와 개인 승급 퀘스트를 제작한다.
- 기존 promotion=1 저장 및 생성 키워드는 보존한다. 신규 단계 규칙과 개인 퀘스트 검증 전 기존 전직을 교체하지 않는다.
- 원화·승급 시스템은 아직 미완료이며 UI 선행 작업과 구분한다.
- 신규 지도 districts-v4 제작·연결: 반복 절벽 감소 및 7개 거점의 건축 차별화. TypeScript 검사 통과. 로컬에서 심연 항구 선택 시 왕관 없는 수문장 해금 안내와 출정 비활성 확인.
