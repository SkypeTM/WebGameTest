# 007 시장 후속 완성

## 작업 목적

기초 시장에 남아 있던 매물 만료, 거래 수수료, 거래 내역을 추가해 실제 플레이에서 거래 생명주기를 확인할 수 있게 한다.

## 변경 파일

- `migrations/001-game.sql`
- `lib/db.ts`
- `lib/store.ts`
- `app/api/game/route.ts`
- `app/page.tsx`
- `tests/store.test.ts`
- `PATCH_HISTORY/007-market-finalization.md`

## 패치 내용

```diff
+ market_listing.expires_at 추가
+ market_history 테이블 추가
+ 24시간 서버 만료 시각 부여
+ 만료 매물의 재료 복구와 판매자 버전 증가
+ 판매 금액 5% 수수료 차감
+ 판매·취소·만료 거래 내역 기록
+ API에 계정별 거래 내역 추가
+ 시장 UI에 만료일·수수료·거래 내역 표시
+ 만료 회수·내역 테스트 추가
```

## 설계 주석

- 만료는 서버 시간이 기준이며 클라이언트 시간이 매물 상태를 결정하지 않는다.
- 구매 수수료는 판매 금액의 5%를 차감하고 판매자에게 순수익을 지급한다.
- 만료·취소 시 재료를 판매자에게 복구한다.
- 거래 내역은 실제 완료·취소·만료 상태만 기록한다.
- 모든 전이는 SQLite 트랜잭션 안에서 수행한다.
