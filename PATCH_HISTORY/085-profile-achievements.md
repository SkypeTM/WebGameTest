# 085 — 마이페이지와 등급 업적 1차

- 계정 정보 창에서 우호도·스토리·재화·수집품·업적 확인.
- 기존 업적 ID를 보존하며 브론즈·실버·골드·전설로 표시.
- 시설 업적 목록을 마이페이지로 이전. 새 업적만 비차단 알림으로 표시.
- 칭호 선택은 서버 게임 저장에 보관하고 미획득 업적 칭호는 거부.
- 공개 친구 UID 및 친구 관계는 별도 서버 식별체계가 필요하여 미완료로 유지.
- 화면 QA/라이브 배포 보류. 코드 검사만 진행.

- TypeScript 및 게임 규칙 검사 통과. 미획득 칭호 거부·선택 저장·기본 칭호 복귀 검사 추가.
