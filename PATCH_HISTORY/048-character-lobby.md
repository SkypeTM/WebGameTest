# 048 — 캐릭터 중심 거점

## 목표
Figma 구조안을 바탕으로 대표 캐릭터, 다음 탐사, 시설 독으로 로비를 정리한다. 기존 시설 내용과 저장·진행 로직은 유지한다.

## 검증 상태
타입 검사 통과. 브라우저 정책 차단으로 로컬 화면 검증은 미완료. 화면 검증 전 배포하지 않는다.

## 변경
- app/components/CharacterLobby.tsx: 선봉 캐릭터, 선택 지역, 출정 준비 버튼, 시설 6개 메뉴.
- app/character-lobby.css: 데스크톱 55/45 배치, 모바일 세로 및 낮은 가로 화면 대응.
- app/page.tsx: 새 로비 연결, 초기 시설 창을 닫아 대표 화면 표시. 출정 준비는 기존 작전실을 열며 즉시 던전에 입장하지 않는다.
- AR1은 신규 투명 전신, 다른 동료는 기존 idle 원화 사용. 다른 캐릭터의 원화 누끼·모바일 시각 검증은 후속 작업이다.
- 계정/파티/지역/탐사 저장 구조는 변경하지 않는다.
