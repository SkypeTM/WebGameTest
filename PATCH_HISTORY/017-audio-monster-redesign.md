# 017 — 사운드와 몬스터 리디자인

## 작업 목적

- 56종 몬스터를 기존 화풍에 맞추되 덜 그로테스크한 형태로 다시 제작한다.
- 생성 이미지를 전투 화면에 연결하고 교체 가능한 매니페스트로 관리한다.
- UI, 카드, 피격, 승리, 보상, 마을과 전투에 필요한 사운드를 추가한다.
- 자원이 허용되는 범위에서 마을·탐사·전투 음악을 게임에 적용한다.

## 패치 내용

- 7개 지역의 56종 몬스터를 기본·행동·피격 3상태, 총 168개 런타임 이미지로 생성했다.
- 모든 몬스터는 둥근 형태, 명확한 실루엣, 고어·신체 공포 배제 지침으로 다시 디자인했다.
- 몬스터 상태 이미지를 전투 모션에 연결하고 기존 자산을 실패 시 대체 자산으로 유지했다.
- 카드 선택, 카드 사용, 피격, 스킬, 경로 이동, 보상, 승리, 패배, UI 클릭 효과음 9개를 제작했다.
- 마을·탐사·전투용 24초 루프 음악 3곡을 프로젝트 전용으로 합성했다.
- 브라우저 자동 재생 정책에 맞춰 첫 입력 후 음악을 시작하고, 헤더에서 음악과 효과음을 각각 끌 수 있게 했다.

## 코드 주석 및 설계 이유

- 브라우저 자동 재생 제한을 지키면서 첫 사용자 입력 이후 오디오를 시작한다.
- 생성 소스와 런타임용 파일을 분리해 이후 교체 비용을 낮춘다.

## 남은 위험 또는 후속 작업

- 합성 음악은 저용량 원본 초안이다. 향후 실제 악기 녹음이나 전문 믹싱 파일로 같은 경로에서 교체할 수 있다.
- 몬스터 시트는 전투 가독성을 우선한 1차 리디자인이며 개별 보스의 연출 프레임은 추가 확장할 수 있다.
