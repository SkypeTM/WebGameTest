# 영지형 애플리케이션 개편 명세

2026-10-24 사용자 요청. 화면 QA는 추후 재개한다.

## 진입 구조
영지 이미지 위 실제 시설 위치를 선택한다. 길드=의뢰·동료모집, 숙소=편성·장비, 주점=이야기·탐사식량, 대장간=무기·방어구 제작, 훈련장=훈련, 교회=치료, 상점=재료 매매. 전리품·출정 로그는 독립 기록 탭.
탐사는 전체 지역 지도→해금된 지역 선택→파티·덱 준비→입장 순서. 잠긴 지역은 조건을 표시하며 진입 불가.

## 후속 구현 계약
- 파티 퀵슬롯은 정확히 5개. 순서·장비·덱을 계정에 저장하고 서버에서 보유 여부를 재검증한다. 기존 저장에는 빈 슬롯을 보충한다. 탐사 중 변경 불가.
- 주점은 대형 캐릭터 이미지, 세부 능력치·스킬트리 우선. 이야기 아이콘은 별도 팝업. 퀘스트 완료와 해당 팩션 우호도를 함께 평가해 장별 해금. 잠긴 이야기 본문은 노출하지 않는다.
- 업적은 브론즈/실버/골드/전설 등급 및 하위/상위 단계. 기존 업적 ID 유지. 신규 획득만 비차단 알림으로 표시하며 로그인 때 과거 업적을 다시 알리지 않는다.
- 마이페이지: 공개용 친구 UID, 칭호 선택, 우호도, 이야기 진행도, 업적, 재화, 수집품. 인증용 계정 ID를 친구 UID로 그대로 노출하지 않는다.
- 영지 전용 원화는 7개 시설의 실루엣과 클릭 위치가 일치해야 한다. 현재 배경 재사용은 임시 단계다.
- 모든 스크롤 영역은 동일 테마 사용. 좁은 화면에서 터치 버튼과 읽기 순서 유지.

## 완료 기준
시설 동작·저장 호환성과 퀵슬롯 서버 저장을 구현한 뒤 사용자 요청 시 실제 화면 QA. 임시 배경/단순 카드 지도는 최종 원화 완료로 간주하지 않는다.

## 지속 작업 규칙
사용자가 '작업 진행'이라고 하면 로드맵의 다음 미완료 항목을 실행하고 진행 상태를 갱신한다. 화면 QA·라이브 배포 보류는 명시적으로 재개하기 전까지 유지한다. 완료되지 않은 항목을 완료로 제거하지 않는다.
