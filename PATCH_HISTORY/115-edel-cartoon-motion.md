# 115 — 에델 전신 모션과 사슬검 연출 교체

## 목적
기본 파티 마지막 인물인 에델의 전신 연출을 카툰 SD와 같은 얼굴·붉은 외갈래 머리·남청 의상으로 맞춘다.

## 변경 사항
- 대기·공격 준비·중간 동작·타격·회수·피격·전용 스킬 7자세를 전투와 연출 미리보기에 연결한다.
- 중간 동작의 칼끝 잘림을 재생성하고, 피격·스킬의 사슬 연결과 가장자리 여백을 보정했다.
- 기본 파티4명의 전신28자세가 모두 새 카툰 경로를 사용한다. 나머지28명의 전신 동작은 이번 패치에 포함하지 않는다.
- 생성 원본·적용 경로·후속 범위를 기록하며 구 자산은 보존한다.

## 변경 파일
- `art-source/cartoon-v5-motion/AR4/`, `public/assets/cartoon-v5-motion/AR4/`
- 전신 모션/진행/생성 manifest, 캐릭터 적용 상태, 로드맵, 작업 인계.

## 확인과 한계
원화 자체 확인 및 배포 빌드만 수행한다. 사용자 요청대로 화면·플레이·자동 QA 생략. 발 좌표·자세별 크기·세부 장식·가장자리 정리와 연속 리깅은 후속 작업이며 현재 개별 자세 전환 방식이다.
