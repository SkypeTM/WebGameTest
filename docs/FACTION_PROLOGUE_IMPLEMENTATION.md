# 팩션 프롤로그·진행 시스템 인계 (041)

## 저장과 호환
기존 Game JSON/계정 저장 및 서버 reducer를 사용한다. 원본 설계는 `docs/design/faction-prologue-v1/`에 보존. 기존 Q01~Q14 ID·보상 유지. 프롤로그가 없는 기존 저장은 재시작하지 않는다.

프롤로그: 7개 기억×4선택 → 정규화 성향 프로필 → 자유로운 8팩션 선택 → Q00 대화. 점수는 우호도에 영향을 주지 않는다. 실제 캐릭터 데이터의 팩션 1~4로 시작하며 임의로 인물 소속을 바꾸지 않는다. Party[0]은 탐사 입장 시 storyLeadId로 고정한다.

## 자유 조사
- 지역마다 두 의뢰의 내부 순서를 지킨다. 열린 지역의 첫 의뢰는 자유롭게 선택한다.
- 지역 의뢰를 완료하면 `lib/progression.ts`의 인접 지역을 연다. 요새↔항구/서고, 항구↔연구동, 서고↔예배당/관측소, 예배당↔연구동, 연구동↔관측소를 왕복하며 조사 가능.
- 궁전은 Q02/Q06/Q08/Q12의 네 증언을 모두 확보해야 열린다. Q14는 Q13 이후.
- BK의 서고 입구에 비공개 회랑 사건 노드, EF의 요새/항구 입구에 피난민 집결지 노드 추가. BK 보급 수락은 암상인 우회 경로를 연다. 독립된 대형 지역을 새로 만든 것은 아니다.
- 다른 지역 일반 적에게 잘못 표시되던 왕검/성탑 예고를 등급별 실제 공격 예고로 수정. 모든 지역은 기존 공통 등급 HP를 사용하므로 지역 번호에 따른 레벨 증폭은 없다. 난이도 체감 검증은 미실시.

## 동료·관계
- 기존 영입 동료는 그대로 유지한다.
- 같은 팩션은 바로 계약 가능. 우호 팩션은 우호도20. 중립은 최대2명 객원 무료 초대 후 신뢰20에서 정식 계약. 적대는 개인 신뢰40 또는 인연 잔향 필요.
- 만날 수 있는 후보는 해금 지역/퀘스트 보상으로 결정한다. 잠긴 인물은 상태/필요 수치를 주점에 표시한다.
- 전투를 거친 안전 귀환: 파티 신뢰+5(보스 돌파+15), 현지 팩션 우호도 및 현지 인물 신뢰+3(돌파+10). 입구 왕복은 성장 없음. 패배는 증가 없음.
- 혼성 팩션 조합으로 두 번 돌파하면 해당 조합 유대 성립: 시작 보호막+3, 승리 후 팩션 대립 스트레스 해소. 개인 대화 분기 대신 현재는 귀환 기록으로 관계 사건을 설명한다.
- 환생은 파티/우호도/퀘스트/제작/증언 방침 초기화. 신뢰30 이상인 최대3명의 인연만 잔향으로 보존하고 신뢰10에서 재회. 이전 회차 캐릭터 전체를 자동 계승하지 않는다.

## 기원 효과
AR 시작 보호막+4 / VR 승리 은화+5 / BC 첫 적 표적+2 / BK 첫 적 표적+3 / WS 생존 동료 회복+3 / DS 첫 턴 마나+1 / GO 보호막+2·첫 적 표적+1 / EF 회복+2·보호막+1. 전투 시작 효과는 선택한 기원에 따른다. 상세 역할/직업은 기존 professionCatalog 유지.

## 증언과 결말
거점에서 확보한 네 증언별 방침(책임/공개/보호/분산)을 기록한다. 엔딩 전에는 수정 가능. Q14 완료 후 해당 방침이 하나 이상 기록된 결말을 선택한다. 네 증언 확보 조건도 서버에서 검증. 기존 회차 엔딩 접근은 유지. 결말 문구와 정책 대응은 `lib/progression.ts`의 endingTexts/endingPolicies. 영상 컷신/음성 분기는 아직 없다.

## 주요 파일
- lib/game.ts: 서버 판정·저장 호환·탐사/보상
- lib/progression.ts: 지역 연결·신뢰 조건·기원 효과·엔딩
- lib/prologue.ts: 성향 연산
- app/components/FactionPrologue.tsx: 선택/Q00
- data/story_dialogues.json: 실제 본편 대사
- docs/STORY_SCRIPT_KO.md: 본편 설명·전체 대본
- docs/AUDIO_GUIDE_KO.md: 음악20곡·효과음28종
- art-source/story-v1/pending.json: 실제 미완료 이미지 목록(기존/추가 요청 포함)

## 남은 범위
개별 수집·호위 목표, 동료별 고유 관계 대화, 고급 전투 기믹과 실제 난이도/청취/모바일 렌더링 QA는 후속 작업이다. 이미지 생성 한도에 걸린 누끼/스킬/상반신/전용 지역 원화는 기존 자산 fallback을 유지한다. 사용자 지시로 플레이/청취 QA는 수행하지 않았다.
