# 103 — 중첩 대화창 조작 복귀

- 자식 대화창을 닫아도 부모 창이 열려 있으면 초점을 복원하지 않던 조건 수정.
- 호출 버튼이 현재 남은 최상위 대화창 안에 있을 때 키보드 초점을 복원한다.
- 다른 대화창 뒤로 초점을 보내지 않으며 스크롤 위치를 유지한다.
- 완료한 3단계 승급 이야기 다시 읽기 제공.
- 실제 Escape 검사에서 자식 cancel 이벤트가 부모까지 전파돼 훈련장이 닫히는 문제 발견. 전파 차단 추가.
- 로컬 Escape 재검증 통과: 훈련장 유지, 승급 의뢰 이야기 버튼으로 초점 복원 확인. 타입 검사 통과. 완료 단계 다시 읽기는 코드 연결 완료, 해당 계정 상태의 화면 검증은 미실시.
