# 079 — 거점 시설 팝업 조작 개선

## 목적
- 실제 태블릿 화면에서 의뢰 패널이 문서 하단에 열리고 포커스가 배경 버튼에 남는 문제 수정.
- 기존 role=dialog 선언에 맞게 실제 모달 동작을 구현.

## 계획
- 네이티브 dialog로 시설 패널을 열어 배경 조작 차단, 닫기 버튼 초기 포커스, Escape 닫기, 원래 버튼 복귀 적용.
- 모바일·태블릿 안전 여백과 스크롤 가능한 콘텐츠 유지.
- 퀘스트 및 시설 내용·저장 로직은 유지.

## 검증
- 구현 후 실제 브라우저 검증 및 TypeScript 검사 예정.

## 완료 및 검증
- HubDialog.tsx 추가, page.tsx 거점 패널 교체, art-direction.css 모달/퀘스트 간격 적용.
- QuestConversation.tsx 종료 시 원래 대화 버튼으로 포커스 복귀.
- 실제 Codex 브라우저: 태블릿 초기 닫기 포커스, NPC 중첩 대화 Escape 복귀, 시설 Escape 닫기와 원래 버튼 복귀 통과.
- 모바일 390×844 퀘스트 팝업 확인. 배경이 접근성 트리에서 제외됨.
- TypeScript 통과. 퀘스트 수락·완료 로직 변경 없음.
- 탐사 QA 추가: 암상인 종료→야영지 휴식→안전 귀환, 은화 136/저장 v22 확인.
- 실기기 터치 및 모든 시설별 거래는 후속 검증 대상.
