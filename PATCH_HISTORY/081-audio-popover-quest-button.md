# 081 — 음량 팝업과 퀘스트 버튼 크기 수정

- 음량 details를 펼치면 콘텐츠가 헤더 높이를 늘리고 음소거 버튼을 세로로 늘리는 문제 수정.
- 음량 콘텐츠를 위치가 분리된 패널로 배치하고 음소거 버튼 높이를 유지.
- 대화 버튼의 문구 너비와 좌우 여백 확보. 기존 대화용 공통 padding과 구분.
- 오디오 값·음소거·계정 저장 로직은 변경하지 않음.
- 실제 화면 검증 예정.

## 검증 결과
- TypeScript 통과.
- 데스크탑 음량 열기/닫기 헤더 높이 152.5px로 동일.
- NPC 대화 버튼 내부 너비/내용 너비 137px 일치, 좌우 padding 14px 확인.
- 모바일 390×844 수첩에서는 음량 패널을 문서 흐름에 배치해 다른 메뉴와 겹치지 않도록 수정.
- 계정의 기존 음소거, 음악 0.25, 효과음 0.75 유지. 설정 변경 없이 UI만 검증.
