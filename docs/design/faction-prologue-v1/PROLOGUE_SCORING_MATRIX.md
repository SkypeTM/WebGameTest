# 프롤로그 팩션 성향 점수표 v1

- 상태: 신규 설계안
- 목적: 프롤로그 선택을 8개 팩션의 `관점 친화도`로 환산
- 원칙: **팩션 배정이 아니라 추천 정보**

## 점수 규칙

- 각 답변은 `Primary +2`, `Secondary +1`을 부여한다.
- 마이너스 점수는 사용하지 않는다.
- 팩션별 문항 노출 빈도가 완전히 같지 않으므로 최종 결과는 raw 합계가 아니라 **정규화 친화도**로 비교한다.
- `Affinity% = RawScore / MaxRawForFaction × 100`
- 동점이면 `Primary 선택 횟수 → M7 선택 관련성 → 동점 공동표시` 순으로 처리한다.
- 최저 점수는 '비추천'이 아니라 `가장 거리가 먼 관점`으로만 표현한다.

## 결과 UI 권장

1. 상위 1개가 2위보다 10%p 이상 높으면 단독 `가장 가까운 관점`으로 표시.
2. 상위 두 팩션 차이가 10%p 미만이면 `두 관점 사이에 서 있습니다`로 공동 표시 가능.
3. 최하위도 동일한 방식으로 공동 표시 가능.
4. 8개 전체 수치는 숫자만 보여주기보다 레이더/막대 형태를 권장하되, '성격 진단의 절대값'처럼 표현하지 않는다.
5. 프롤로그 결과는 저장하되 `originFaction`과 분리한다.
