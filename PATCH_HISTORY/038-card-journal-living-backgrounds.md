# 038 · 카드 이미지 통일, 행동 기록 팝업, 움직이는 배경

## 작업 목적
손패와 덱/도감의 카드 원화를 일치시키고 기록을 아군/적 방향별 팝업으로 표시합니다. 기존 배경 위에 애니메이션 레이어를 추가합니다.

## 검증 정책
사용자 지시에 따라 이번 추가 작업은 QA를 수행하지 않습니다. 배포에 필요한 빌드는 진행합니다.

## 변경 파일
- `app/page.tsx`: 공통 카드 원화 선택 함수, 덱/도감 카드 이미지·코스트 아이콘 통일, 기록 버튼, 배경 효과 및 토글 연결.
- `app/components/ActionJournal.tsx`: native dialog 기반 기록 팝업. 아군 왼쪽, 적 오른쪽, 탐사 사건 가운데 배치. 최근 기록으로 자동 이동.
- `lib/game.ts`: 기존 문자열 저장 형식을 유지하며 신규 행동에 진영 접두어 추가. 적의 실제 체력 피해·보호막 흡수·방어·준비 행동 기록. 이전 저장의 캐릭터 행동 문장은 이름으로 분류.
- `app/components/LivingBackdrop.tsx`, `app/living-scenes.css`: 기존 배경 위 SVG/CSS 애니메이션 레이어. 요새/거점의 깃발과 순찰병, 야외 비/설원 눈, 항구/서고 물줄기·물결, 등불·낙엽·안개. 화면을 가려도 입력을 차단하지 않음.

## 구현 범위와 제한
- 기존 패치의 AR1~AR4 전용 카드 원화와 SD 이미지 폴백을 공통 사용. 이번 작업에서 모든 카드 원화를 새로 생성한 것은 아님.
- 배경은 다층 2D 애니메이션이며 Cubism Live2D 모델 파일이 아님. 깃발·순찰병 등은 SVG 도형으로 새로 제작하고, 움직임은 CSS 키프레임으로 구현.
- 메뉴에서 배경 움직임 정지 가능. 백그라운드 탭에서는 일시정지하며 OS 동작 줄이기 설정을 존중.
- 기록은 기존 서버 정책대로 최근 24건만 보관. 과거 저장에는 적 행동 기록이 없어 소급 복원하지 않음.
- 사용자 요청으로 QA/브라우저 플레이/추가 테스트 생략. 배포용 프로덕션 빌드만 수행.
