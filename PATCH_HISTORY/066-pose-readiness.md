# 066 · 원화 준비 대기 및 잔상 단축

065 화면에서 자세 전환 시 검·방패가 겹치는 잔상 확인. 크로스페이드100→35ms 단축, 이동 보간은 유지. 미리보기는 선택 캐릭터 원화를 decode한 뒤 재생을 시작하고 실패 시 재시도 제공. 게임의 기존 로그인 원화 사전 로딩은 유지하며 판정/타격 시점에 로딩 대기를 추가하지 않는다.
