# 018 — 시네마틱 탐사와 전투 연출

## 작업 목적

- 참고 영상의 전신 캐릭터, 횡스크롤 탐사, 좌측 파티·우측 적 전장 구도, 카드 귀속 표현을 현재 게임에 맞게 재구성한다.
- 지역마다 구분되는 탐사·전투 배경을 제작하고 마을부터 던전까지 시각 흐름을 연결한다.
- 턴 전환, 공격, 피격, 스킬, 대화 장면의 모션과 정보 전달을 강화한다.

## 변경 파일

- `app/page.tsx`
- `app/style.css`
- `data/environment_manifest.json`
- `public/assets/environments/expedition/*.png` (7개)
- `PATCH_HISTORY/README.md`

## 패치 내용

- 참고 영상에서 확인한 횡스크롤 탐사 무대, 좌측 파티·우측 적 구도, 캐릭터 귀속 카드, 대화 초상 연출을 현재 세계관에 맞게 재구성했다.
- 변경 요새, 옛 항구, 지하 서고, 예배당, 뿌리 성소, 잿빛 마을, 종탑의 16:9 탐사·전투 배경 7개를 생성했다.
- 탐사 화면에 현재 지역 무대, 1~4열 파티 행진, 선택한 목적지 표식을 추가했다.
- 전투 화면에 지역 배경, 턴 전환 배너, 4단계 행동 안내, 원형 턴 종료 버튼을 추가했다.
- 손패에 카드 소유 캐릭터 초상을 합성하고 선택·호버 시 카드가 앞으로 떠오르도록 조정했다.
- 아군 대기, 적 호흡, 탐사 행진, 목적지 강조 모션을 추가하고 모션 감소 환경 설정을 존중한다.
- 휴식·수수께끼·팩션 이벤트에 현재 선두 캐릭터의 대화 초상과 상황별 대사를 추가했다.
- PC와 모바일에서 배경, 전투 정보, 카드, 이벤트 대화가 겹치지 않도록 반응형 배치를 보강했다.

## 코드 주석 및 설계 이유

- 참고 작품의 고유 캐릭터·화면을 복제하지 않고 공간 구도와 피드백 원칙만 적용한다.
- 기존 서버 저장 및 카드 전투 규칙은 유지하고 표현 계층을 확장한다.

## 남은 위험 또는 후속 작업

- 현재 모션은 상태별 일러스트 전환과 CSS 키프레임을 조합한다. 프레임 단위 스프라이트 애니메이션은 후속 제작 대상이다.
- 각 지역은 대표 배경 한 장을 공유한다. 방 단위 변형 배경과 보스 전용 시네마틱은 후속 확장 대상이다.
- 참고 영상의 고유 캐릭터·UI·장면은 복제하지 않았으며, 화면 구도와 피드백 원칙만 적용했다.
