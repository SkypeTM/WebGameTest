# 042 렌더링 인계

- 탐사 대형과 일반 캐릭터 표현은 투명 SD를 우선 사용. AR 대화 상반신은 새 투명 원화 우선. 신규 상반신이 없는 캐릭터의 대화 전용 원화는 이전 fallback 유지.
- 암상인의 동일 이미지를 3번 배치하던 잘린 레이어를 제거하고 하나의 연속된 인물로 렌더링. 새 투명 암상인6종은 생성 한도 대기이며 현 원본의 불투명 배경은 아직 남아 있다.
- 버프/디버프·반격·스트레스·부상·표식·기절은 아이콘+중첩 수. 호버/포커스/터치 시 viewport 고정 툴팁. 카드 타깃 클릭으로 전파하지 않는다. unit-readout 내부 스크롤 제거.
- 체력바는 초록 HP와 파랑 보호막으로 분할. 보호막 획득/소모 미리보기도 표시. 큰 보호막은 HP+보호막 합계로 같은 바 안에 표현하며 호버/접근성 이름으로 수치 제공.
- 카드 선택 중 비대상 영역 클릭/탭, Esc, 유효 대상 밖 드롭, pointercancel로 기본 상태 복귀. 타깃 클릭·정상 드롭은 유지.
- 전용 스킬 카드에 SD fallback 금지. 준비된 전용 그림, 같은 캐릭터의 신규 강공/타격 그림, 기존 전용 상태 일러스트 순으로 사용. 재사용 그림은 전용 스킬 신규 제작으로 집계하지 않는다.
- LivingBackdrop: 기존 배경 원화에 실시간 WebGL 셰이더로 물결 변형·안개·광원·강수/눈·광선을 적용. 조잡한 SVG 깃발/경비병은 제거. 기존 낙엽 유지. 캐릭터와 상호작용 UI는 셰이더 대상이 아니다.
- 전투/탐사/거점/사건/상점/유물/프롤로그/NPC 대화에 연결. 방 ID 대신 실제 지역으로 배경을 선택한다. WebGL 불가 시 정지 배경, 화면 밖/비활성 탭 중단, reduced-motion 지원.
- 새 연구동/관측소/궁전 전용 배경은 생성 대기. 현재는 기존 서고/종탑/요새 원화를 해당 지역 조명·날씨로 활용. 실제 영상/GIF나 Wallpaper Engine 프로젝트 파일을 만든 것은 아니다.

프롬프트와 실제 생성 대기 목록: art-source/story-v1/generation-plan.json, pending.json. QA는 사용자 지시로 미실시.
