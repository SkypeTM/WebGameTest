# 093 — 캐주얼 원화 교체와 세계 지도 일러스트

- 사용자 요청으로 이미지 생성 재개. 공통 자연스러운 디자인 정책 적용.
- 7개 지역을 담은 전용 세계 지도 원화 제작 및 기존 선택/잠금 기능 연결.
- 전체 기존 자산은 목록화하여 교체 진행률을 기록. 미완료 자산을 완료로 표시하지 않음.
- 세계 지도 이미지 적용, 기존 SVG 지형 제거, 원화 위치에 지역 버튼 좌표 조정. 잠금·출정 기능 유지.
- AR1 새 전신 원화는 주점 상세에만 적용. 생성 결과 배경이 남아 있어 전투 누끼 사용은 보류.
- 교체 후보 598개를 casual_art_replacement_queue.json에 기록. 구형/비사용 항목 포함 가능, 전부 런타임 사용 중이라고 단정하지 않음.
- TypeScript 검사 통과. 전체 교체·라이브 반영 미완료.

## 세계 지도 규모 축소
- 대륙형 해안·사막·광대한 산맥을 줄이고 일곱 탐사 거점이 연결된 몰락 왕국의 좁은 계곡으로 재구성.
- 침묵한 종탑, 검은 조류의 항구, 침수 기록실, 봉쇄 연구동·성문 등 세계관 요소 반영.
