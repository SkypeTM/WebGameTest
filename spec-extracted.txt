문서와 파일 사용 순서
본 문서의 확정 요구사항을 우선하고, 초기값이라고 표시된 수치는 조정 가능한 기본값으로 사용한다. data/monsters.json과 data/characters.json의 ID를 유지한다. 이전 개요와 충돌하면 이 명세를 적용한다. 사용자 추가 지시가 오면 해당 내용이 우선한다.
art 폴더의 AI 콘셉트 시트는 방향을 검토하는 원화다. 개별 투명 스프라이트·애니메이션·완성 UI가 아니다. 준비된 그림은 적용하되 없는 자산은 명확히 표시한 임시 자산으로 교체 가능하게 만들고, 게임 기능 구현을 중단하지 않는다.

화면 구성과 전투 및 탐험
게임 화면
로그인 → 저장된 상황 이어하기 또는 거점 → 모집·4인 편성·장비·덱 준비 → 맵과 의뢰 선택 → 경로·방·전투·사건 → 귀환 정산 순서로 진행한다. 거점에서 시설, 팩션, 퀘스트, 시장, 기록과 환생을 연다. 진행 중인 탐사가 있으면 새 탐사를 중복 생성하지 않는다.
PC 전투는 왼쪽 파티, 오른쪽 적, 하단 손패, 상단 상태와 적 행동 예고를 기본으로 한다. 모바일 세로 화면은 적 영역·파티 상태·손패 순으로 압축하고 카드 탭 후 대상 탭으로 실행한다. 작은 화면에서 가로 스크롤 없이 핵심 행동을 완료할 수 있어야 한다.
카드 전투 초기값
캐릭터당 시작 카드 4장으로 최대 16장 파티 덱을 구성한다. 첫 구현은 턴당 행동 자원 4, 손패 6장, 보관 상한 10장을 기본값으로 둔다. 턴 종료 시 보존 효과 없는 손패를 버리고 다음 턴 6장까지 뽑는다. 드로 덱이 비면 버린 카드를 섞는다. 사용자가 확정한 수치가 아니므로 데이터에서 변경 가능하게 한다.
적의 다음 행동을 먼저 보여준 뒤 카드 비용 지불·대상 검증·효과·전투 불능·승패를 서버에서 처리한다. 전투 불능 인물의 카드는 사용 불가로 표시하고 드로에서 제외한다. 부활 시 다시 사용 가능하게 한다. 파티 전원 전투 불능이면 실패한다. 초기안은 영구 사망 대신 부상과 미확보 전리품 손실을 적용한다.
탐험과 몬스터 배치
각 맵은 연결된 방의 그래프로 만든다. 일반 전투, 정예, 퍼즐, 팩션 조우, 휴식, 보스, 귀환 가능한 방을 배치한다. 확정된 결과와 무작위 시드를 저장하고 같은 방 재방문으로 보상을 중복 지급하지 않는다. 각 맵의 전용 8종을 역할에 맞게 조합하며 보스는 별도 조우다.
첫 밸런스는 일반 적 HP 30·공격 6, 정예 HP 70·공격 12, 보스 HP 180·공격 18부터 테스트한다. 난이도와 인원 보정은 별도 설정으로 두며 모든 맵을 같은 수치의 외형 교체로 완성 처리하지 않는다. 특수 행동·예고·공략은 부록의 각 몬스터 설계를 구현한다.
퍼즐과 조작
문양 해독, 장치 경로, 대가를 요구하는 제단을 제공한다. 필수 퍼즐은 항상 풀 수 있고 막힐 때 단서가 있어야 한다. 키보드는 보조 수단이며 호버나 드래그만 가능한 핵심 조작은 만들지 않는다. 클릭·터치 영역은 44 CSS px 이상을 목표로 한다.

서막: 종소리와 탐사대 실종을 조사한다. 1막: 8개 팩션의 입문·후속 의뢰로 장부, 봉인문, 기억 수액, 통행원장을 확보한다. 2막: 길드와 숲 선택을 마친다. 3막: 정치 주체와 심연 대응을 선택한다. 종막: 종탑 거신을 쓰러뜨리고 선택한 의식을 수행한다.
입문 의뢰는 양쪽 수행 가능하다. 배타적 퀘스트 한쪽을 완료하면 반대편은 해당 회차에서 포기 상태로 고정한다. 초기 보상은 선택 팩션 우호도 +25, 반대편 −30이다. 전달·보상·상대 잠금은 한 번에 저장한다. 우호도 회복으로 잠긴 분기를 되돌리지 않는다.
입문과 후속 의뢰 제목
왕국: 끊긴 봉화 → 왕의 빚. 공화연맹: 시민의 명부 → 공개되지 않은 회의. 조합: 돌아오지 않은 표식 → 구조의 대가. 결사: 닫힌 문 너머 → 빚 없는 밤. 교단: 꺼진 성화 → 성인의 공백. 성회: 같은 꿈을 꾸는 자들 → 별 아래의 언어. 수호회: 병든 나이테 → 숲이 기억한 이름. 해방전선: 돌아갈 집 → 재 속의 약속.
파티 관계 초기안
대척 네 쌍은 확정이다. 우호 관계의 초기안은 왕국–교단, 공화연맹–해방전선, 조합–수호회, 결사–성회이며 나머지는 중립이다. 유저 우호도와 팩션 간 관계를 분리한다. 대척 편성은 허용하고 같은 팩션 쌍은 인원 수와 무관하게 한 번만 계산한다.
초기값: 대척 쌍당 전투 후 스트레스 +2, 파티 전체 추가량 최대 +4. 우호 쌍당 전투 시작 보호막 5, 최대 10. 같은 팩션 2·3·4명은 각각 방어 보정 5·8·10% 중 최고 단계만 적용한다. 단일 팩션 4인은 대척 NPC 협상 비용 +10%를 추가한다. 수치는 데이터로 조정한다.
필수 스토리 NPC는 랜덤 추첨에 의존하지 않는다. 반대 진영과 적대해도 선택 루트의 진행을 회복할 의뢰나 대체 담당자가 존재해야 한다. 초기에 영입은 영구 명부 등록으로 구현하되 환생 시 명부 처리에는 아래 초기안을 적용한다.

엔딩 조합
왕국+재봉인: 침묵을 지키는 왕관. 공화연맹+재봉인: 봉인을 나눈 의회. 왕국+교신: 별을 품은 왕좌. 공화연맹+교신: 새벽 없는 연맹. 길드와 숲 선택은 각 주 엔딩의 후일담에 반영한다. 기본 4개 주 엔딩과 16개 전체 조합을 도달 가능하게 한다.
환생의 확정 규칙과 초기안
현재 루트의 필수 스토리 퀘스트를 완료하고 엔딩을 본 뒤 선택 실행한다. 미선택 분기의 포기 퀘스트는 완료 조건에서 제외한다. 경험치·레벨·우호도·스킬과 스토리 선택은 초기화한다. 훈련 스탯·진급·진화·업적 능력 보상도 초기화한다.
구현용 초기안: 계승품 최대 3개, 중첩 물품은 개별 수량으로 계산한다. 퀘스트 물품과 희생 보상은 제외한다. 장비 강화·룬은 기본 상태로 환원한다. 명부·시설·화폐는 초기 상태로 돌리고 기본 시작 파티를 지급한다. 엔딩·업적 기록은 표시만 유지하며 능력은 주지 않는다. 이 항목들은 과거 미결정 사항에 대한 기본 제안이므로 설정으로 분리한다.
최종 확인 화면에서 사라질 항목과 계승품을 보여준다. 진행 중 탐사를 종료하고 플리마켓 매물·정산을 먼저 해결한 뒤 환생한다. 거래 대금을 다음 회차에 수령해 초기화를 우회하지 못하게 한다.

맵 조우와 세 종류의 시장
맵별 팩션 조우
일반 방 첫 진입에서 기본 조우율을 판정하고 맵별 팩션 분포로 주체를 고른다. 요새는 왕국·공화연맹, 항구는 두 길드, 서고·예배당은 두 종교, 성소·옛 마을은 숲지기·해방전선 비중이 높다. 종탑은 모든 세력이 등장한다. 맵별 분포의 합은 100%로 검증한다.
초기 관계는 0, 범위 −100~100. 적대 −40 이하, 경계 −39~−10, 중립 −9~19, 우호 20~49, 동맹 50 이상. 우호도가 높으면 보급·엄호·정보·희귀 의뢰를 늘리고 낮으면 검문·추적·습격을 늘린다. 기본 조우가 없는 방에 추가 관계 사건을 판정해 실제 지원 또는 불리한 사건의 수가 변하게 한다.
시장별 동작
시장
기능과 완료 기준
팩션 상점
왕국은 군장비, 공화국은 공방품, 조합은 탐사품, 결사는 잠금·은신 도구, 교단은 성물, 성회는 촉매, 수호회는 약초·목재, 해방전선은 야전 물품 취급
수수료
경계 12%, 중립 8%, 우호 4%, 동맹 1% 초기값. 구매는 기준가에 가산, 판매는 매입가에서 차감. 적대 시 해당 상점 제한
플리마켓
유저 등록·검색·구매·취소·만료·내역. 등록품은 보관 처리. 구매 시 대금과 소유권 함께 이전. NPC 가상 매물로 완성 처리하지 않음
암시장
재료 교환, 탐사 한정 저주, 치료 필요 부상, 회차 제한, 멤버 희생 거래. 대상·효과·기간·해제 조건·보상을 사전에 공개

플리마켓 초기 수수료는 5%로 팩션 우호도와 분리한다. 동일 상품 매입가는 판매가보다 낮게 두어 무한 차익을 점검한다. 퀘스트품, 장착품, 희생 대가 보상은 거래 제한한다. 암시장 희생은 선택 사항이며 주 스토리 진행의 필수 조건이 아니다.
우호 NPC가 파티 내 대척 인물을 보고 협상 조건을 추가할 수 있으나 이유를 표시한다. 지원 NPC는 해당 사건의 일회 효과이며 상시 5번째 파티원이 되지 않는다. 관계 효과와 상점 조건은 서버에서 계산한다.

계정 저장과 구현 구조
실시간 저장의 의미
계정으로 로그인한 뒤 마지막 확정 상태에서 이어한다. 카드 사용·보상·장비 변경·퀘스트·거래·강화·환생은 각각 서버 저장과 함께 확정한다. 전투 턴, 적 상태, 손패·덱 순서, 행동 자원, 체력·스트레스, 선택 대기 사건과 미확보 전리품까지 복원한다.
연결이 끊기면 다음 진행 입력을 멈춘다. 같은 행동의 재전송에는 같은 결과를 반환하고 비용이나 보상을 중복 적용하지 않는다. 기기 전환 시 세션의 조작 권한을 넘겨받고 기존 기기는 중지한다. 저장 버전 충돌을 시간순 덮어쓰기로 처리하지 않는다.
권장 구현안
기존 저장소가 있으면 구조와 지침을 먼저 따른다. 신규라면 TypeScript, React 기반 Next.js, PostgreSQL을 기본 제안으로 삼되 호환되는 안정 버전을 공식 문서로 확인하고 고정한다. 인증은 검증된 라이브러리를 사용한다. 로그인 화면만 구현하거나 localStorage를 계정 저장으로 간주하지 않는다.
게임 규칙은 UI와 분리한 결정적 함수로 작성한다. 브라우저는 행동 의도를 전송하고 서버가 현재 상태·소유권·비용·턴을 검증한 후 결과를 계산한다. 캐릭터·몬스터·카드·아이템·팩션·퀘스트·균형 수치는 데이터로 관리한다.

캐릭터와 몬스터 아트 가이드
캐릭터는 모두 성인으로 디자인한다. 여성 30명·남성 2명은 모집 가능한 서로 다른 원형의 비율이며, 앞으로 로스터를 늘릴 때도 여성 비율 90% 이상을 유지한다. 전투 파티마다 여성 비율을 강제하는 규칙은 아니다. 팩션마다 수호·공격·지원·제어 역할을 제공한다.
인물은 키·골격·얼굴형·눈매·코·피부색·연령감이 다르게 설계된다. 같은 얼굴과 체형에 의상만 교체하지 않는다. 각 인물의 정면·측면·후면 전신, 세 가지 얼굴 표정, 무기·소품을 개별 시트로 제공한다. 탐험용 축소 자산은 이후 같은 인물 기준으로 파생한다.
몬스터는 매끄러운 외곽선, 둥근 형태, 선명한 색과 읽기 쉬운 공격 예고를 사용한다. 공포는 스토리와 배경 분위기에 남기고 시체·노출된 신체·다수의 눈 같은 그로테스크 요소는 사용하지 않는다. 유리톱니 기계군은 고대 관리 로봇의 오작동 세력이며 기존 8개 모집 팩션과 별개의 적 분류다.
몬스터 56종은 7개의 맵별 콘셉트 시트로 검토한다. 각 시트는 왼쪽 위부터 오른쪽 아래 순서의 8종이며 M번호가 설계 데이터와 연결된다. NPC는 art/characters 폴더의 ID_design_sheet.png로 연결한다. 생성 자산의 실제 준비 상태는 asset_manifest.json을 확인한다.
AI 원화에 그려진 수치·문자·카드 UI를 게임 UI로 사용하지 않는다. 체력·아이콘·버튼·텍스트는 별도 화면 요소로 렌더링한다. 원화에서 개별 자산 제작 시 배경 제거, 발 기준점, 크기, 좌우 방향, 피격 영역을 정리하고 전투 실루엣을 확인한다.
데이터 필드
몬스터: id, map, rank, name, silhouette, action, tell, counter, loot, enemyFaction. 캐릭터: id, faction, name, gender, age, role, design, heightCm, body, face, skin, signature, sheet. 헤어스타일이 충돌하면 signature를 우선한다. 데이터의 행동 설명을 화면에 표시만 하는 것으로 구현을 완료 처리하지 않는다.
자산 품질의 한계와 처리
콘셉트 시트는 개별 몬스터 56개의 투명 PNG나 완성 애니메이션이 아니다. 그림의 작은 차이와 ID 표기 오류가 발견되면 JSON의 ID와 설계를 우선한다. 실제 게임 자산으로 제작한 상태와 콘셉트·임시 상태를 asset manifest에 분리해 기록한다.
