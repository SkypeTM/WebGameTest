# 120 — 전문화와 심화 성장 분기

## 목적
훈련장의 기존 Lv.3 전문화에 Lv.7 심화 선택을 연결하고, 주점에서도 현재 성장 경로를 확인할 수 있도록 한다.

## 성장 규칙
- Lv.3 맹공·수비·집중의 기존 효과는 유지한다.
- Lv.7부터 현재 전문화에 속한 심화 두 가지 중 하나를 고를 수 있다.
- 맹공: 강타(공격 +2) 또는 정밀(치명타 +4%p).
- 수비: 철벽(방어 +2) 또는 반격 준비(공격 +1·방어 +1).
- 집중: 주문 숙련(주문 +2) 또는 안정(주문 +1·방어 +1).
- 보유 동료를 거점에서 무료 변경한다. 별도 성장 포인트는 소모하지 않는다.
- 전문화를 바꾸면 기존 전문화의 심화 선택은 해제된다. 자동 재선택하지 않는다.
- 기존 저장은 심화 미선택으로 유지하며, 기존 승급·카드 키워드 해금은 변경하지 않는다.
- 성장 선택은 캐릭터 단위다. 편성 퀵슬롯에 복사하거나 덮어쓰지 않는다.

## 구현 구성
- `lib/skill-tree.ts`: 분기 ID·조건·보정의 공통 정의. 게임 모듈을 가져오지 않는다.
- `app/components/CharacterSkillTree.tsx`, 전용 CSS: 훈련장의 선택형 화면과 주점의 열람형 화면.
- `lib/game.ts`, `app/page.tsx`, `TavernDossier.tsx`에 공통 정의를 연결한다. 서버에서 거점·보유·레벨·부모 분기를 재검사하고, 능력치에 한 번만 합산한다.
- `app/character-lobby.css`: 주점에서는 전체 너비 성장 경로, 훈련장에서는 동료별 펼침 영역으로 배치한다.
- `data/SPECIALIZATION_SYSTEM_KO.md`: 저장·조건·효과·구현 계약 기록.

## 확인 범위
사용자 요청으로 화면·플레이·자동 QA를 생략한다. 빌드·배포 상태는 릴리스 담당자가 따로 기록한다.
심화 수치는 이번 성장안의 초기 값이며 실제 플레이 밸런스 검증은 아직 진행하지 않았다.
