# 022 — 직업·장비 제한·추천 파티 배치

## 작업 목적

- 캐릭터별 직업과 역할, 장비 제한, 직업별 스탯을 체계화한다.
- 주점과 상세창 정보를 전투 판단 중심으로 바꾸고 추천 자동 배치를 제공한다.

## 변경 파일

- `lib/game.ts`: 직업·전투 역할·추천 위치·스탯·장비 제한 규칙
- `app/page.tsx`: 파티 자동 배치, 직업/특성/스킬/주점 상세 UI
- `app/style.css`: 직업 정보와 팝업의 PC·모바일 반응형 스타일
- `tests/game.test.ts`: 직업 장비 제한과 추천 배치 검증

## 패치 내용

- 32명 캐릭터를 8개 직업으로 분류하고 직업별 능력치와 역할을 적용했다.
- 직업에 맞지 않는 장비는 UI와 서버 양쪽에서 차단한다.
- 캐릭터 카드에 팩션 아이콘, 직업, 세부 역할, 추천 전열 위치를 표시한다.
- 특성과 전용 스킬 설명을 팝업으로 확인할 수 있다.
- 주점 모집 정보를 직업·레벨·전투 능력치·장비 중심으로 개편했다.
- 추천 위치 우선순위로 파티를 정렬하는 자동 배치 버튼을 추가했다.

## 검증 결과

- `npm test`: 23개 통과
- `npm run typecheck`: 통과
- `npm run build`: 통과
- PC 화면에서 파티 편성, 자동 배치, 상세 팝업, 주점 정보 표시 확인

## 남은 작업

- 직업별 성장 및 상위 장비 제작은 후속 패치에서 확장한다.
