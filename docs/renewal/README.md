## UI 방향: Silent Bell / 원정 기록극
배경과 캐릭터가 주인공, 정보는 화면 가장자리. 금색 테두리 상자 반복, 영어 장식 소제목, 모든 정보 동시 나열을 줄인다.
- 로비: 대표 캐릭터 좌측 55%, 우측 하단 출정 CTA 하나, 시설 5개 하단 독. 재화/설정은 상단. 시설 상세는 한 개의 시트만.
- 전투: 좌측 아군(4→1)·우측 적, 하단 겹친 손패, 좌측 코스트 구슬, 우측 턴 종료. 적 의도/HP 항상 유지. 이름+핵심 수치만 표시, 상세는 길게 누르기/호버.
- 탐사: 지도 중심, 현재 노드·연결 경로 강조. 상세 노드는 하단 시트. 출정 전에 보상/위험/파티 미리보기.
- 모바일 가로 우선: 전투 높이 100dvh, 스크롤 없는 손패 조작. 세로는 전장 상단 55%, 손패 하단 30%, 상세 시트. 태블릿 두 방향 모두 별도 검증.
- 토큰: 배경 #10191E, 패널 #1B292F, 본문 #F3EFE3, 보조 #9AAEB3, 강조 #E4BD70, 회복 #82C9B3, 피해 #D87572, 보호막 #66B8ED. 색만으로 상태 구별하지 않는다.
- 기본 타이포: 본문 14~16px, 보조 12px 이상, 버튼 44px 이상. 애니메이션 중 레이아웃/스크롤 위치 고정.

## 엔진 판단
현재 Next.js/React + 서버 authoritative 게임 reducer는 유지. 전투 렌더러를 격리해 PixiJS 8 WebGL 후보와 현재 DOM 렌더러를 AR1 시제품으로 비교한다. WebGPU만 강제하지 않는다. 브라우저 웹 게임을 Unity 전체 이식하는 비용은 현재 정당화되지 않았다.
합격 기준: 중급 모바일에서 4아군+3적, 60fps 목표/최저 30fps, 연출 입력 중복 없음, WebGL context 복구, 감소된 모션, 네트워크 재시도에서 결과 중복 적용 없음. 실제 기기 측정 전 성능 보장 금지.
