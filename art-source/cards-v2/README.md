# Card illustrations v2

Built-in imagegen output, four individual square illustrations, no text or border. Each references the corresponding original SD character to retain face, hairstyle, outfit and palette.

Prompts: AR1 shield counterattack; AR2 spear piercing a target sigil; AR3 healing with brass medical kit; AR4 binding rune chains. Dynamic inked anime fantasy card composition in a subdued ruined fortress.

Original PNGs are stored here; `node scripts/build-card-art.mjs` converts them to quality-94 WebP in `public/assets/cards-v2` and writes `data/card_character_art.json`.
