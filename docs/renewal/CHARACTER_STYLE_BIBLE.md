# 캐릭터 화풍 기준 v2

## 고정 방향
성인 캐릭터의 정제된 애니메이션 원화. 또렷한 실루엣, 깨끗한 선, 2~3단 셀 음영에 절제된 재질 표현. 얼굴의 과도한 실사 질감·금속 과노출·장식 과밀·금색 입자 남발을 피한다. 현재 원화는 정체성 참조이며, 거친 유화 질감은 새 스타일의 기준이 아니다.

## 비율과 표현
- 전신: 7~7.5등신, 성인 골격과 얼굴. SD: 2.5~3등신, 같은 헤어 실루엣·장비·색상.
- 여성 외형은 만19~35세로 명확하게 설계. 작은 키/작은 체형도 성인으로 읽히는 얼굴·손·골격. 장난기, 과묵함, 안경, 성숙한 리더, 음침함, 사교 서투름 등은 표정과 행동으로 구분.
- 체형은 슬림/운동형/풍만/장신/아담형으로 다양화. 얼굴, 성격, 역할, 무기 실루엣을 먼저 결정한다.
- 표정 neutral/explain/resolve/hurt/smile의 눈·눈썹·입 모양, 손동작을 정의. 부정확한 손가락이나 얼굴 비대칭은 합격 처리하지 않는다.

## 자산 계약
- 기준 시트: 정면/측면/후면, 얼굴 확대, 눈/머리/피부/직물/금속 팔레트, 무기 크기, 좌우 액세서리 위치.
- 전투: 단일 캐릭터 실제 알파 WebP/PNG, 1536px 이상 높이 목표, 전체 발/머리 여백 8%, 기준점 (0.5,0.94). 생성 원본이 작으면 실제 크기를 기록하고 FHD라고 표기하지 않는다.
- 포즈: idle, ready, windup, strike, recover, guard, hit, skill. 각 자세의 머리 크기와 발 기준점 동일. 부위가 잘린 조각 이미지를 이어붙이지 않는다.
- 대화: 허리 위 크롭, 같은 카메라·광원, neutral는 가슴 앞 손, explain은 열린 손바닥, resolve는 무기/가슴으로 모은 손. 표정별 시선 일관.
- 카드: 정사각형 동작 구도, 얼굴 중앙 60% 안, 텍스트/테두리 없이. 실제 게임의 스킬명/효과를 확인하고 제작.

## 생성 규칙
각 캐릭터 시트의 fixedIdentity + targetDesign + styleVersion을 프롬프트에 반드시 포함. 같은 승인된 기준 시트를 참조해 파생하며 파생 이미지로 다시 정체성을 추론하지 않는다. 현행/목표가 다른 항목은 목표 시트를 먼저 새로 생성하고 전체 묶음을 전환한다. 얼굴·헤어·눈색·무기손·의상 레이어 변경은 디자인 버전을 올린다.

## 검수 체크
정체성/성인 외형/비율/의상 구조/손·발/무기 방향/알파/기준점/실제 해상도/작은 카드 식별/배경 대비. 이미지 수만 채우는 것으로 완료하지 않는다. 승인 자산 경로와 SHA256을 결과 manifest에 기록.
