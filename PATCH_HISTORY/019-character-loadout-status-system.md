# 019 — 캐릭터 장비 상세창과 상태·카드 트리거

## 작업 목적

- 작게 보이던 캐릭터·장비 이미지를 확대하고 캐릭터 카드에서 상세 장비창을 연다.
- 캐릭터별 전투 능력치, 성장 정보, 특성, 스킬을 실제 게임 상태와 연결한다.
- 카드 드래그 중 피해·회복·보호막 결과를 체력바 위의 색상 구간으로 미리 표시한다.
- 전투 상태 효과와 카드 전용 트리거를 공통 규칙 및 UI에 도입한다.

## 패치 내용

- 캐릭터 카드 이미지를 확대하고 클릭 가능한 상세 장비·능력치 창을 추가했다.
- 무기·방어구·장신구 각 3종과 장착 이미지, 실제 공격·방어·주문 보정을 서버 저장 상태에 연결했다.
- 체력, 마나, 스트레스, 공격력, 방어력, 주문력, 치명타, 특성, 전용 스킬, 경험치 바를 추가했다.
- 기본 공격·방어·강공격 카드 아트 3종을 새로 제작하고 전용 스킬은 캐릭터 스킬 일러스트를 사용한다.
- 카드 드래그 중 체력바에 피해·회복·보호막 예상 구간을 색상으로 겹쳐 표시한다.
- 중독, 출혈, 광기, 도벽, 약화, 표적, 치명타, 취약, 가시, 격노, 기절, 분노, 화상, 동상, 감전, 전염병, 반격, 피해 차단, 은신, 공포 상태 정의와 전투 처리를 추가했다.
- 복사, 보존, 소멸, 생성, 발견, 사용불가 카드 트리거 정의와 카드 처리·도감을 추가했다.
- 스킬 카드에 캐릭터별 마나 소비와 턴별 회복을 적용했다.
- 이전 저장 데이터에는 장비 슬롯, 마나, 상태, 소멸 카드 더미 기본값을 자동으로 채운다.

## 코드 주석 및 설계 이유

- 첨부 이미지는 정보 계층과 상호작용 참고 자료로만 사용하며 고유 캐릭터·카드 이미지는 복제하지 않는다.
- 새 필드는 이전 저장 데이터에도 기본값을 채워 이어하기가 가능하도록 정규화한다.
