# 075 — 여정 정리와 패치 기록 팝업

## 목적
완료된 작업 설명은 패치 기록으로 옮기고, 앞으로의 여정에는 남은 작업만 표시한다.

## 변경
- 게임과 여정 페이지에서 검색 가능한 패치 기록 팝업 제공.
- Git 추적 중인 패치 문서를 공개 JSON으로 생성하여 필요할 때만 로드.
- 문서는 HTML 실행 없이 일반 텍스트로 표시. GitHub 원문 링크 제공.
- 완료 상태 항목은 여정 목록에서 자동 제외.
- 정식·임시 배포 명령에 테스트와 플레이 봇 선행 검사를 추가. 실패하면 빌드·배포가 실행되지 않음.

## 검증
공개 기록 74개의 Git 추적 문서 일치·정렬·중복 검사 포함 테스트 49/49 통과.
플레이 봇 3/3, 원화 28/28, 지도 700/700 통과. Next.js TypeScript·프로덕션 빌드 통과.
직접 브라우저 화면 검증은 미완료. 원화 확장·스토리·실기기 검증 등 미완료 작업은 로드맵에 유지.
