# 055 · 공개 작업 현황과 로컬 플레이 봇

요청: 남은 작업을 게임에서 열람하고 반복 플레이 검증 비용을 줄인다.
구현 예정: 공개 /roadmap 페이지, 게임 연결, 구조화된 작업 데이터, 로컬 격리 플레이 봇 및 JSON/Markdown 결과.
봇은 실제 게임 reducer로 프롤로그·탐사·전투·보상·귀환을 실행한다. 사용자 저장을 수정하지 않으며 UI/음향/로그인/네트워크 검증을 대체하지 않는다. 실패 시 종료 코드1, 자동 배포 없음.
검증 및 배포: 진행 중.

구현 완료: /roadmap 공개 페이지 및 게임 헤더 새 창 링크. data/roadmap.json을 공개 현황의 단일 원본으로 사용. qa:bot와 Windows 실행 파일 추가. 실제 reducer 격리 실행, 잘못된 이동 거부·직렬화·버전·체력 범위 확인. 사용자 DB/계정/저장 파일 접근 없음.
검증: 봇 3/3 PASS(20/23/22행동), 타입 검사 통과. 내부 브라우저 현황 페이지·완료 기준 펼치기 확인. 게임 원래 탭은 URL 정책 차단으로 링크 클릭 확인 미실시. UI·음향·인증 통합 QA 대체 아님.

배포: 468fb5c4-e5c9-45c5-8137-78dbdf3681e1. /roadmap·/·/m HTTP200, 공개 현황 HTML 및 신규 게임 JS가 빌드와 바이트 일치. 로컬 서버 재시작. 라이브 화면 열기는 내부 브라우저의 기존 연결 실패 페이지 정책으로 미완료(로컬 현황 화면은 검증 완료).
