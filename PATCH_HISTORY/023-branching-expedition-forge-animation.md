# 023 — 분기 탐험·직업 무기 제작·전투 연출

## 작업 목적

- 4계층 분기 던전과 보스 경로를 구현한다.
- 거점 시설 안에서 직업별 무기를 제작하고 성장 재료를 사용한다.
- 상인·휴식지·랜덤 조우와 사망 후 보상 연출을 실제 플레이 흐름에 연결한다.

## 변경 파일

- `lib/game.ts`: 분기 경로, 상인, 랜덤 조우, 제작법, 귀환 규칙
- `app/page.tsx`: 계층 지도, 시설 내부 탭, 제작·상인·보상 화면
- `app/style.css`: 2D 프레임 전환, 타격·사망 모션, 반응형 지도
- `tests/game.test.ts`, `tests/store.test.ts`: 신규 흐름과 저장 검증

## 패치 내용

- 매 탐사에 전투·상인·휴식·물음표가 포함되는 4계층 분기 지도와 보스를 추가했다.
- 서로 다른 노드가 다음 계층의 여러 노드로 연결되며, 7개 지역의 몬스터군을 귀환 횟수에 따라 순환한다.
- 휴식지에서만 정상 귀환할 수 있고 패배 귀환과 기존 저장의 마지막 봉화는 호환한다.
- 던전 상인에서 희귀 재료 구매, 유료 회복, 기본 공격 카드 진화·삭제·변경을 지원한다.
- 거점 시설 내부에 대장간·훈련장·치료실·식당 탭을 만들고 8개 직업용 상위 무기 4종 제작을 추가했다.
- 계정 창고 재료와 은화를 서버에서 검증해 제작하고 제작한 무기만 장착할 수 있다.
- 기존 32명 캐릭터 192장, 56종 몬스터 168장의 상태 이미지를 프레임 객체로 연결해 공격·피격 모션에 사용한다.
- 몬스터는 잘리지 않는 기본 프레임으로 피격하며 마지막 적은 1.25초 사망 모션 뒤 보상이 열린다.
- 전투 보상에 재료 이미지와 파티원별 경험치 증가량을 표시한다.

## 남은 작업

- 퀘스트 보상은 이후 퀘스트 시스템에서 현재 제작 재료 저장 구조에 연결한다.
- 프레임 보간과 본 애니메이션은 향후 전용 리깅 자산으로 더 세밀하게 확장할 수 있다.
