# 111 — 전32명 SD 원화 경로 전환

## 목적과 적용
- GO 실바·에린·바르나·리스, EF 레나·유나·다리아·세이 SD 8종 제작·연결.
- `data/sd_asset_manifest.json`의 플레이어 32명 모두 `cartoon-v5-sd` 경로로 전환했다. 이전 파일은 보존한다.
- `public/assets/cartoon-v5-sd/`, `art-source/cartoon-v5-sd/`, 생성 프롬프트와 진행 JSON을 함께 저장한다.
- 기존 캐릭터 ID·전투 계산·저장 호환성은 유지한다.

## 확인과 남은 범위
- 생성 원화에서 얼굴·헤어·무기 손·전체 실루엣을 직접 확인했다.
- 사용자 요청으로 화면·플레이·자동 QA 생략. 배포용 빌드는 수행한다.
- 전신 모션·대화 표정·승급·NPC·몬스터·카드는 별도 미완료다. SD 경로32명 연결이 전체 아트 전환 완료를 뜻하지 않는다.
- 개별 장식·굽·여백·모션 중 시각 정합은 후속 정리 대상이다.
