# 064 · 중간 원화와 느린 반복 재생

AR1 기본 공격의 준비→타격 사이 swing 원화를 생성한다. 기존 스킬/다른 캐릭터 fallback 유지. 미리보기에 0.25/0.5/1배속 및 반복을 추가한다. 실제 게임은 기본1배속과 타격320ms·종료900ms를 유지한다. 원화 생성은 연속 관절 리깅과 다르다.

범위를 기본 파티4명으로 확장. 각 swing 원화 생성 및 기존 디자인·무기 손 육안 비교. 전체28자세. 220ms 중간 동작,320ms 타격 유지.

검증: 원화28/28, 플레이3/3, 빌드·타입 통과. 라이브79aec5e8-2bd3-4bf0-8ef6-a36d0bad97cc에서 0.25배속 CSS3.6초, 반복 on/off, 중간 자세 선택 확인. 390x844에서 scrollWidth375≤innerWidth390. 체크박스가 공통 input 스타일로 과도하게 커지는 후속 UI 수정 필요.
