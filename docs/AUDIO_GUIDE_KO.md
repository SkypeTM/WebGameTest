# 오리지널 음악·효과음 인계 (041)

## 제작
외부 음원/샘플 없이 직접 작성한 악보와 결정적 합성기로 생성했다. 사람의 연주 녹음이나 보컬이 아닌 절차적 신시사이저 음원이다. 32kHz 16bit stereo WAV. 음악20곡, 효과음28종. 원본·게임 파일은 `public/assets/audio/v2/`, 목록은 `data/audio_manifest_v2.json`, 생성 코드는 `scripts/compose-soundtrack.mjs`.

기존 `public/assets/audio/music/`, `sfx/`, `scripts/generate-audio.ts`의 미커밋 작업은 덮어쓰지 않는다. v2는 독립 경로를 사용한다.

## 악곡
각 곡은16마디, 약28~64초. 주선율·화성 패드·저음·벨·플럭·플루트와 상황별 타악기를 합성한다. 잔향과 음의 꼬리를 처음으로 감아 루프 경계를 처리하고 피크/RMS 기준으로 출력 레벨을 조정한다.

| 상황 | 곡 |
|---|---|
| 프롤로그 기억 | 두 번째 종은 울리지 않았다 |
| 결과·기원 선택·Q00 | 여덟 갈래의 새벽 |
| NPC 대화 | 남겨진 목소리 |
| 거점 | 귀환자의 등불 |
| 변경 요새 | 사흘째 봉화 |

| 침수 서고 | 젖은 종이의 이름 |
| 예배당 | 대답 없는 성가 |
| 연구동 | 유리 속의 메아리 |
| 관측소 | 움직이는 북쪽 별 |

## 런타임
`lib/audio.ts`에서 게임 상태로 트랙을 선택한다. 첫 포인터/키 입력 이후 재생한다. BGM650ms 전환, 효과음8개 동시 재생 제한, 비활성 탭 일시 정지, 로그인 해제 시 중단. 음악/효과음 볼륨과 음소거는 기기의 localStorage에 저장된다(게임 계정 진행도와 독립). 브라우저 자동재생 거부 시 강제 재생하지 않는다.

기억 선택, 기원 확정, 대화 넘김, 퀘스트 수락·완료, 카드 선택·사용, 타격·방어·회복, 상태 이상, 제작·거래·영입, 유물 선택, 보스 조우, 승리·패배·귀환·환생 효과를 연결했다. 음악과 동명 효과음은 `music-`/`sfx-` 파일 접두어로 분리한다.

## 재생성
`node scripts/compose-soundtrack.mjs`
동일 악보와 seed로 동일한 음원을 만든다. 외부 서비스/유료 API가 필요하지 않다. 개발 버전에서는 트랙별 WAV를 필요할 때만 내려받는다. 향후 연주 악기/보컬 또는 압축 포맷은 이 manifest 경로로 교체할 수 있다.

사용자 지시로 브라우저 청취 및 플레이 QA는 생략했다. 빌드/컴파일 확인과 실제 청취 품질 검증을 혼동하지 않는다.
