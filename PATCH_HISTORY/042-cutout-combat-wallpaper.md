# 042 · 투명 캐릭터·전투 표시·라이브 배경

요청: 캐릭터 누끼, 암상인 분절 수정, 아이콘 상태 툴팁, 파랑 보호막 게이지, 카드 외부 선택 해제, 일러스트 스킬 카드, 지역별 고품질 움직이는 배경.

원인: 탐사 장면이 불투명 FHD 자산 사용, 암상인 원본을 clip-path로 중복 배치, 상태 텍스트와 고정 높이 overflow, 지역 ID 대신 방 ID로 배경 조회.

새 투명 암상인·전용 스킬 원화 생성은 이미지 한도로 대기. 기존 투명 SD 및 캐릭터 일러스트를 활용하고 분절 렌더링부터 제거한다.

## 구현 결과
투명 SD 우선 표시, 암상인 단일 이미지 모션, 상태 툴팁, 파랑 보호막 미리보기, 카드 외부 선택 해제 적용. SD 카드 fallback 대신 동일 캐릭터 일러스트 재사용. WebGL 배경 물결·안개·조명·날씨 적용, SVG 깃발·경비병 제거. 지역 조회 오류 수정.
