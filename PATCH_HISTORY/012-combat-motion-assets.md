# 012 전투 무한 턴 방지와 시각 연출

## 작업 목적

턴 종료가 끝없이 반복되는 상황을 서버에서 제한하고, 캐릭터·몬스터·카드의 의미 있는 시각 자산과 공격·피격 모션을 플레이 화면에 연결한다.

## 변경 예정 파일

- `data/balance.json`
- `lib/game.ts`
- `app/page.tsx`
- `app/style.css`
- `tests/game.test.ts`
- `PATCH_HISTORY/012-combat-motion-assets.md`

## 설계 주석

- 턴 상한은 클라이언트가 아니라 reducer에서 검증한다.
- 카드와 전투 대상의 모션은 마지막 확정 상태에 저장되는 `combatFx` 이벤트로 표현한다.
- 실제 외부 이미지가 없어도 캐릭터·몬스터·카드의 의미를 읽을 수 있는 교체 가능한 CSS/SVG 자산을 사용한다.
- 카드 효과의 내용은 기호 하나가 아니라 전용 아트 컴포넌트와 설명으로 함께 전달한다.

## 패치 내용

```diff
+ `maxBattleTurns: 40` 추가
+ 최대 턴 도달 시 전투를 defeat로 종료
+ `CombatFx` 이벤트를 서버 확정 상태에 저장
+ 카드 사용 시 공격·방어·회복 이벤트 기록
+ 몬스터 공격·캐릭터 피격 이벤트 기록
+ 캐릭터·몬스터 자산에 모션 클래스 연결
+ strike, guard, heavy, skill별 카드 SVG 아트 추가
+ 공격 돌진, 방어 펄스, 회복 글로우, 피격 흔들림 애니메이션 추가
+ 전투 화면에 `현재 턴 / 최대 턴` 표시
+ 최대 턴 및 후속 턴 거절 테스트 추가
```

## 검증 결과

- IDE 진단: 수정 파일 오류 없음
- 운영 빌드 실행
- 최대 턴 전투 종료 회귀 테스트 추가

## 남은 위험

현재 아트는 코드로 생성한 교체 가능한 SVG/CSS 자산이다. 최종 제작 이미지·스프라이트 시트·사운드는 별도 에셋이 필요하다.
