# 054 · 지도 연결선 가독성

목적: 지난 경로, 이동 가능한 경로, 선택한 경로를 구분하고 연결선과 노드 중심을 일치시킨다.
변경: app/page.tsx, app/route-briefing.css. 진행 및 저장 규칙은 유지한다.
검증: 타입 검사 및 내부 브라우저 선택·취소 확인 예정.

구현: 기본 연결선 1px, 지난 경로 2px 실선, 이동 가능 청록 점선, 선택 경로 금색 3px 실선. 노드 중심(bottom4%)과 SVG 연결선(기존94%)의 2% 위치 차이를96% 기준으로 수정. 선택 aria-pressed 및 현재 위치 aria-current 추가.
검증: 타입 검사·diff 공백 검사 통과. 내부 브라우저는 URL 정책 차단으로 미검증. 사용자에게 localhost 새로고침 요청. 배포 보류.
