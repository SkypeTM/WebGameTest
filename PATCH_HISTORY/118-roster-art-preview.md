# 118 — 전체 동료 SD 원화와 전신 연출 미리보기

## 목적
기본 파티 4명만 선택할 수 있었던 미리보기를 전체 동료 32명의 SD 원화 확인 화면으로 확장한다. 준비된 전신 자세와 SD 원화를 구분하여 제공한다.

## 구현 범위
- 공개 캐릭터 데이터와 SD·전신 자세 manifest에 등록된 자산만 사용한다.
- 팩션별 캐릭터 선택, 이전·다음 동료 이동, 현재 선택 이름과 사용 가능한 원화 종류를 표시한다.
- SD 보기는 전체 동료를 지원한다. 전신 전투 보기는 준비된 자세 세트가 있는 기본 파티 4명만 지원한다.
- 전신 세트가 없는 동료를 선택하면 SD 보기로 전환한다. SD 이미지를 전신 이미지처럼 확대하지 않는다.
- 기본 공격·피격·전용 스킬, 개별 자세, 재생 속도, 반복 재생을 유지한다. 프레임 측정은 전신 모드에서만 표시한다.
- 선택한 동료·보기의 원화만 미리 읽고, 로딩 실패 시 재시도한다. 빠른 선택 변경 후 이전 캐릭터의 로딩 결과가 표시되지 않도록 한다.
- 모바일 선택 영역의 줄바꿈, 터치 버튼, 키보드 초점과 원화 설명을 보완한다.
- 이미 배포된 7개 지역 배경과 승급 미리보기를 로드맵에서 계속 제작 중으로 표시하던 문구를 정리한다. 배포 상태와 실제 화면 QA는 구분한다.

## 변경 파일

- `data/roadmap.json`, `data/region_preparation_art_v4.json`, 패치 인덱스와 인계 기록

## 확인 범위
사용자 요청으로 브라우저·플레이·자동 QA는 생략한다. 배포 빌드와 실제 배포 결과는 `storage/qa` 릴리스 기록에 별도로 남긴다.
새 원화 생성, 기존 전투 계산과 저장 데이터 변경은 포함하지 않는다. 전신 자세 미지원 동료는 화면에 그대로 안내한다.
